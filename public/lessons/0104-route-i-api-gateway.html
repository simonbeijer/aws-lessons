Lektion 104

Route i API Gateway

Vad du ska veta efter lektionen Att en route är metod plus sökväg, att {id} blir pathParameters.id, och att ett anrop utan matchande route får 404 utan att funktionen körs.

Var ligger routen?

Routen ligger i API Gateway, inte i koden. I Express skrev du routen i koden med app.get. Nu skriver du den i ditt HTTP API, som metod plus sökväg. (AWS: Routes for HTTP APIs)

Ditt API får fem routes. I konsolen ser du dem under Develop → Routes.

GET    /customers
POST   /customers
GET    /customers/{id}
PUT    /customers/{id}
DELETE /customers/{id}

Vad gör {id}?

Klammerparenteserna gör id till en sökvägsparameter, som :id i Express. Det som står på den platsen i anropet hamnar i event.pathParameters.id, som du såg i eventet. (AWS: Path variables)

Anropet GET /customers/abc-123 matchar GET /customers/{id}, och koden får "abc-123". Saknas klammerparenteserna i routen blir pathParameters tom, och koden hittar inget id.

Ingen matchande route

Matchar ingen route svarar API Gateway själv 404 med {"message":"Not Found"}, och funktionen körs inte. Anropet syns därför inte i funktionens logg i CloudWatch Logs. (AWS: Routing API requests; statuskoden och loggen: kursmaterialet v42)

Både API Gateway och koden kan svara 404. Kroppen visar vem som svarade.

Route matchar GET /customers/{id}. Funktionen körs, hittar ingen kund och svarar 404 med {"error":"customer abc not found"}.

Ingen route Sökvägen /products finns inte. API Gateway svarar 404 med {"message":"Not Found"}.

Ingen route Sökvägen finns, men inte med metoden DELETE. API Gateway svarar 404 med {"message":"Not Found"}.

Quiz

1. GET /products får 404 med {"message":"Not Found"}. Vad har hänt?

2. Routen är GET /customers/{id}. Var hamnar abc-123 i anropet GET /customers/abc-123?

3. Repetition från lektion 57: vad svarar Express om ingen route matchar anropet?

Sammanfattning

  • En route i API Gateway är metod plus sökväg. Den ligger i API Gateway, inte i koden.
  • {id} i routen gör id till en sökvägsparameter, som hamnar i event.pathParameters.id.
  • Matchar ingen route svarar API Gateway 404 med {"message":"Not Found"}, och funktionen körs inte.
