Lektion 52

JSON

Vad du ska veta efter lektionen Att JSON är formatet som kroppen skrivs i, både i anropet och i svaret, och att JSON är strikt: ett enda fel tecken gör att servern svarar 400.

Vad är JSON?

JSON är textformatet som kroppen skrivs i, åt båda hållen. Headern Content-Type: application/json säger att kroppen är JSON. (kursens lektion sida 14, MDN: Working with JSON, RFC 8259)

Klienten skickar en ny kund:

{ "name": "Carol" }

Servern svarar med kunden som skapades:

{ "id": 3, "name": "Carol", "created_at": "2026-10-08T15:05:00Z" }

Du har sett JSON förut: policyn AdministratorAccess i lektion 5 är skriven i JSON.

Hur JSON skrivs

Det som står inom { } kallas ett JSON-objekt. Det är något annat än ett objekt i S3. JSON-objektet har par av namn och värde, med kolon emellan och komma mellan paren. Namnet står alltid inom dubbla citattecken. (MDN: Working with JSON)

VärdeExempelSkrivs
Text"Carol"Inom dubbla citattecken.
Tal3Utan citattecken.
Sant eller falskttrueUtan citattecken.
Lista[1, 2]Inom [ ].

JSON har ingen typ för datum. Därför skickas datum som text, som created_at ovan. (kursens lektion sida 36, RFC 8259)

Vad händer om JSON:en har ett fel?

Ett fel tecken gör att kroppen inte är JSON. Då svarar kursens server 400. Enkla citattecken, ett komma efter sista paret eller en avbruten kropp räcker. Klicka och jämför: (kursmaterialet v41, MDN: Working with JSON)

{"name":"Carol"}

Svar: 201 Created. Carol skapas.

{"name":

Svar: 400 Bad Request och body is not valid JSON.

Servern kontrollerar också varje värde: {"name":""} är giltig JSON men ger ändå 400 och name is required. (kursmaterialet v41)

3. Repetition från lektion 5: i AdministratorAccess står paret "Effect": "Allow". Vad betyder det?

Sammanfattning

  • JSON är textformatet som kroppen skrivs i, både i anropet och i svaret. Content-Type: application/json säger att kroppen är JSON.
  • Ett JSON-objekt är par av namn och värde inom { }. Namn och text står inom dubbla citattecken. Datum skickas som text.
  • JSON är strikt. Ett fel tecken, t.ex. enkla citattecken, ger 400 från servern. Även giltig JSON kontrolleras: ett tomt namn ger också 400.
