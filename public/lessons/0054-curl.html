Lektion 54

curl

Vad du ska veta efter lektionen Hur curl -i skickar ett HTTP-anrop från terminalen och visar hela svaret, och hur -X, -H och -d sätter metod, header och kropp.

Vad är curl?

curl är ett kommando som skickar ett HTTP-anrop från terminalen och skriver ut svaret. Det finns redan i appen Terminal på din Mac. (curl: man page, kursmaterialet v41)

Utan något mer skickar curl GET och skriver bara ut kroppen. En flagga är ett tillägg efter ett bindestreck som ändrar vad kommandot gör. Flaggan -i skriver också ut startraden och headers. Kursens poäng: curl visar exakt vad servern svarade. Prova mot en öppen testserver, eller klicka och jämför: (curl: -i, kursens lektion sida 19 och 36)

curl -i https://jsonplaceholder.typicode.com/posts/1
{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere ...",
  "body": "quia et suscipit ..."
}

Bara kroppen.

HTTP/2 200
content-type: application/json; charset=utf-8
content-length: 292
...

{
  "userId": 1,
  "id": 1,
  "title": "sunt aut facere ...",
  "body": "quia et suscipit ..."
}

Hela svaret: startrad, headers, tom rad och kropp.

-X, -H och -d bygger anropet

-X sätter metoden, -H lägger till en header och -d skickar kroppen. Så här skapar du ett inlägg med POST: (curl: man page, kursens lektion sida 19)

curl -i -X POST https://jsonplaceholder.typicode.com/posts \
  -H "Content-Type: application/json" \
  -d '{"title":"Hej från curl","userId":1}'

\ sist på en rad betyder att kommandot fortsätter på nästa rad. De enkla citattecknen gör att terminalen lämnar JSON-texten orörd. (Bash: Escape Character)

Svaret blir 201 Created och ditt JSON-objekt med ett nytt "id": 101. Testservern sparar inget, den låtsas bara. (kursmaterialet v41)

Varför -H behövs

Utan -H skickar -d kroppen med Content-Type: application/x-www-form-urlencoded, formatet för webbformulär. Då läser kursens server inte kroppen som JSON och svarar 400, som i lektion 51. (curl: -d, kursmaterialet v41)

Sammanfattning

  • curl skickar ett HTTP-anrop från terminalen. Utan flaggor blir det GET, och bara kroppen skrivs ut.
  • -i visar hela svaret: startrad, headers, tom rad och kropp. curl visar exakt vad servern svarade.
  • -X sätter metoden, -H en header och -d kroppen. Skickar du JSON med -d: lägg till -H "Content-Type: application/json".

Källor

Huvudkälla: curl: man page (flaggorna -i, -X, -H och -d).
