Lektion 85

Duration och Billed Duration

Vad du ska veta efter lektionen Vad fälten på REPORT-raden säger om tid och minne, och att Billed Duration är den tid du betalar för, med Init Duration inräknad vid en kallstart.

Vad är Duration?

Duration är tiden handlern tog att köra anropet, i millisekunder. Fältet står på REPORT-raden, direkt efter RequestId. (AWS: REPORT line data fields)

RequestId är anropets id. Det är samma id som handlern får i context. Samma id står på anropets övriga rader i loggen, så du hittar alla rader som hör till ett anrop. (AWS: Log format, AWS: Context object)

Vad är Billed Duration?

Billed Duration är tiden AWS tar betalt för. Den är Duration avrundad uppåt till hel millisekund. Vid en kallstart läggs Init Duration till före avrundningen. Därför skiljer sig de två fälten. (AWS: Billing for INIT phase)

Det är körtiden från lektion 77. På Free plan räknas den mot körtiden som ingår varje månad. (AWS: Free Tier, Serverless)

REPORT RequestId: 57f231fb-…  Duration: 79.67 ms  Billed Duration: 80 ms  Memory Size: 128 MB  Max Memory Used: 73 MB

79,67 avrundas uppåt till 80.

REPORT RequestId: c793869b-…  Duration: 128.83 ms  Billed Duration: 296 ms  Memory Size: 128 MB  Max Memory Used: 74 MB  Init Duration: 166.62 ms

128,83 + 166,62 = 295,45, avrundat 296.

Vad visar minnesfälten?

Memory Size är minnet funktionen har fått, i megabyte (MB). 128 MB är standard och det minsta. Mer minne ger också mer processorkraft, men samma tid kostar mer. (AWS: Configure memory, AWS: Lambda pricing)

Max Memory Used är det mesta funktionen använde. Ligger det nära Memory Size behöver funktionen kanske mer minne. (AWS: REPORT line data fields, AWS: Appropriate memory setting)

Quiz

1. Ett anrop var en kallstart. Vad räknas in i Billed Duration?

2. Max Memory Used ligger nära Memory Size. Vad säger det?

3. Repetition från lektion 84: när har REPORT-raden fältet Init Duration?

Sammanfattning

  • Duration är tiden handlern tog. RequestId är anropets id, samma som i context.
  • Billed Duration är tiden du betalar för: Duration, plus Init Duration vid en kallstart, avrundad uppåt till hel millisekund.
  • Memory Size är minnet funktionen fått, Max Memory Used det mesta den använde. Mer minne ger mer processorkraft men kostar mer per millisekund.
