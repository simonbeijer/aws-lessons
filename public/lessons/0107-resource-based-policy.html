Lektion 107

Resource-based policy

Vad du ska veta efter lektionen Att policyn på funktionen säger vem som får anropa den, och att rollen säger vad funktionen själv får göra.

Vad är en resource-based policy?

En resource-based policy är en policy som sitter på själva resursen, här din Lambda-funktion, och säger vem som får använda den. Det är samma idé som en bucket policy: policyn säger själv vem den gäller, i Principal. (AWS: Resource-based policies in Lambda)

I konsolen ser du den under Configuration → Permissions, längre ned under Resource-based policy statements. Varje statement är en regel. (AWS: Viewing a function's resource-based policy)

Vad står i regeln?

Regeln släpper in API Gateway. API Gateway-konsolen lägger till den när du skapar integrationen. Förenklad ser den ut så här: (AWS: API Gateway permissions)

{
  "Effect": "Allow",
  "Principal": { "Service": "apigateway.amazonaws.com" },
  "Action": "lambda:InvokeFunction",
  "Resource": "arn:aws:lambda:eu-north-1:123456789012:function:v42-api"
}

apigateway.amazonaws.com är API Gateways namn som tjänst. lambda:InvokeFunction betyder att anropa funktionen. Regeln har också ett villkor: bara anrop från ditt API räknas. (AWS: API Gateway permissions)

Saknas regeln körs funktionen aldrig. Klienten får bara {"message":"Internal Server Error"}. (AWS: Troubleshooting HTTP API Lambda integrations)

Vad skiljer den från rollen?

Skillnaden är riktningen. Execution role säger vad funktionen får göra, till exempel läsa tabellen. Resource-based policy säger vem som får köra funktionen. Två riktningar, två policyer.

Sammanfattning

  • En resource-based policy sitter på funktionen och säger vem som får använda den. Du ser den under Configuration → Permissions → Resource-based policy statements.
  • Regeln ger apigateway.amazonaws.com rätt till lambda:InvokeFunction, bara från ditt API. Konsolen lägger till den åt dig. Saknas den får klienten Internal Server Error.
  • Rollen säger vad funktionen får göra. Policyn på funktionen säger vem som får köra den. Två riktningar, två policyer.
