Lektion 116

Meddelande i SQS

Vad du ska veta efter lektionen Att ett meddelande är en text, ofta JSON, som ligger i fältet Message body. När det skickas ger kön det ett message ID.

Vad är ett meddelande?

Ett meddelande är en text som du skickar till kön. Texten står i fältet Message body och måste ha minst ett tecken. Den får vara JSON, XML (Extensible Markup Language, text med taggar) eller vanlig text. Producenten skriver den, och konsumenten läser den senare. (AWS: SendMessage)

Vad är ett message ID?

Message ID är en identifierare som SQS sätter på meddelandet när det skickats. Du väljer den inte. Svaret på skickandet innehåller den, och det visar att kön tog emot meddelandet. Meddelandet ligger sedan kvar i kön. (AWS: Message identifiers)

Sammanfattning

  • Ett meddelande är en text i Message body: JSON, XML eller vanlig text.
  • SQS sätter ett message ID när meddelandet skickas, och svaret innehåller det.
  • Meddelandet ligger kvar i kön efter att det skickats.
