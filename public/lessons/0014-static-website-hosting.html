Lektion 14

Static website hosting

Vad du ska veta efter lektionen Hur en bucket blir webbserver, och varför du först får 403 Forbidden.

Hur blir en bucket en webbserver?

Du slår på Static website hosting, en inställning längst ned under fliken Properties i bucketen. Då skickar S3 bucketens objekt till webbläsare som ber om dem. Det är vad en webbserver gör. (AWS: Enabling website hosting)

Static betyder att filerna skickas precis som de ligger: HTML, CSS, JavaScript och bilder. Ingen kod körs hos S3. (AWS: Hosting a static website)

Endpoint och index document

Endpoint är bucketens webbadress, och index document är dess startsida. Klicka för mer. (AWS: Website endpoints, AWS: Index document)

Sidans webbadress. Den syns under Static website hosting som Bucket website endpoint. I eu-north-1, med ditt bucketnamn först: http://bucketnamn.s3-website.eu-north-1.amazonaws.com. Bara http, inte https.

Filen S3 visar när adressen inte nämner någon fil, oftast index.html. Objektets key måste heta exakt så, med samma små och stora bokstäver.

Varför får du 403 Forbidden?

För att ingen ännu har fått rätt att läsa objekten. 403 Forbidden är felkoden en webbserver svarar med när du inte får se sidan. (AWS: Permissions for website access)

Endpointen visar bara objekt som alla får läsa. Att Block Public Access är av räcker inte. En bucket policy som ger alla läsrätt löser det. (AWS: Website endpoint)

403 Forbidden

Du får inte läsa filen.

404 Not Found

Filen finns inte, till exempel fel namn.

Quiz

1. Du har slagit på Static website hosting och öppnar endpointen. Du får 403 Forbidden. Varför?

2. Du skriver in endpointen utan något filnamn efter. Vilken fil visar S3?

3. Repetition från lektion 13: varför måste Block all public access vara av för en publik webbsida?

Sammanfattning

  • Static website hosting, under Properties, gör bucketen till webbserver. S3 skickar filerna precis som de ligger.
  • Bucketen får en endpoint, en http-adress. Utan filnamn i adressen visar S3 index document, oftast index.html.
  • Du får 403 Forbidden tills någon ger alla rätt att läsa objekten. Det gör en bucket policy, nästa lektion.
