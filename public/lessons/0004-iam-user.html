Lektion 4

IAM user

Vad du ska veta efter lektionen Vad en IAM user är, och hur den skiljer sig från root user.

Vad är en IAM user?

En IAM user är en egen inloggning som du skapar inne i ditt AWS-konto. Den har ett namn och egna inloggningsuppgifter, till exempel ett lösenord. (AWS: IAM users)

IAM (Identity and Access Management) är AWS-tjänsten där du bestämmer vem som får logga in och vad de får göra. Du hittar den genom att söka på IAM i konsolen. (AWS: What is IAM?)

En IAM user hör till ett enda konto. Allt den gör faktureras det kontot. (AWS: IAM users and accounts)

Hur loggar den in?

Med kontonumret, sitt användarnamn och sitt lösenord. Kontonumret är tolv siffror och syns i menyn uppe till höger i konsolen. Root user loggar i stället in med kontots e-postadress. (AWS: Sign in as an IAM user)

Kontot har också en egen inloggningsadress där kontonumret redan är ifyllt. (AWS: Sign in to the console)

https://123456789012.signin.aws.amazon.com/console

Root user

Kontots e-post och lösenord. Kan göra allt

IAM user

Kontonummer, användarnamn och lösenord. Till vardags

Vad får den göra?

Från början ingenting. En ny IAM user får inte göra något förrän du ger den behörighet, alltså rätt att göra vissa saker. (AWS: IAM users and permissions)

Även med full behörighet är den inte root user. Uppgifter som kräver root, som att låta IAM users se fakturering, kan den inte göra. (AWS: IAM users, AWS: Tasks that require root)

Sammanfattning

  • En IAM user är en egen inloggning som du skapar i ditt AWS-konto, i tjänsten IAM.
  • Den loggar in med kontonummer, användarnamn och lösenord. Root user loggar in med kontots e-postadress.
  • En ny IAM user får inte göra något förrän du ger den behörighet. Även med full behörighet kan den inte göra det som kräver root.
