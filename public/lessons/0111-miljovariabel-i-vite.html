Lektion 111

Miljövariabel i Vite

Vad du ska veta efter lektionen Att VITE_API_URL i .env.local och i Amplify byggs in i sidans JavaScript, så att adressen syns för alla som öppnar sidan.

Var står variabeln?

En miljövariabel i Vite är ett namn med ett värde som sidans kod får, här VITE_API_URL med API:ets Invoke URL. Bara namn som börjar på VITE_ når sidans kod. (Vite: Env Variables and Modes)

Lokalt står den i filen .env.local:

VITE_API_URL=https://ab12cd34ef.execute-api.eu-north-1.amazonaws.com

Filen ska inte med i någon commit, så den når aldrig GitHub. Amplify får därför ett eget värde, under Hosting → Environment variables → Manage variables. (AWS: Setting environment variables)

Koden läser den med import.meta.env, som process.env i lektion 44:

const API = import.meta.env.VITE_API_URL;

Byter du API, byter du värdet, inte koden. (kursmaterialet v42)

När läses den?

Värdet läses när Vite startar. npm run dev startar Vites utvecklingsserver, ett program som visar sidan på http://localhost:5173. Ändrar du filen: starta om. (Vite: Env Variables and Modes)

Vid bygget byter Vite ut import.meta.env.VITE_API_URL mot adressen i filerna i dist/. Amplify bygger med sitt värde, så ett nytt gäller efter nästa bygge. Saknas variabeln blir värdet undefined, som i lektion 94.

Vem kan se den?

Alla som öppnar sidan ser den. Adressen står i sidans JavaScript, och anropen syns i Network-fliken. (Vite: Env Variables and Modes)

I lektion 44 fanns lösenordet bara på servern. Här får varje webbläsare värdet.

Varning

Lägg aldrig ett lösenord eller en nyckel i en VITE_-variabel. Adressen till API:et får synas. (AWS: Amplify environment variables)

Du byter värdet på VITE_API_URL. Välj var:

Utvecklingsservern läste filen när den startade. Stoppa npm run dev och starta den igen.

Gäller efter omstart

Sidan på Amplify har den gamla adressen inbyggd i dist/. Den nya kommer med i nästa bygge.

Gäller efter bygget

Då står adressen i koden, inte i en variabel. Varje byte blir en ny commit.

Quiz

1. Du ändrar VITE_API_URL i .env.local medan npm run dev körs. Vad händer?

2. Du sparar ett nytt värde på VITE_API_URL i Amplify. När når det sidan?

3. Repetition från lektion 44: DB_PASSWORD låg i en miljövariabel på servern. Varför får lösenordet inte ligga i en VITE_-variabel?

Sammanfattning

  • VITE_API_URL står i .env.local på din dator och under Hosting → Environment variables i Amplify. Koden läser den med import.meta.env.VITE_API_URL. Bara namn som börjar på VITE_ når sidan.
  • Vite läser värdet vid start och bygger in det i filerna i dist/. Ändrar du .env.local: starta om npm run dev. Ändrar du i Amplify: värdet gäller efter nästa bygge.
  • Värdet står i sidans JavaScript och syns för alla. Adressen får synas, men aldrig ett lösenord eller en nyckel.
