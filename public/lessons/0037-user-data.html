Lektion 37

User data

Vad du ska veta efter lektionen Att user data är ett skript som körs en gång vid första start, och var du ser om det gick fel.

Vad är user data?

User data är ett skript du ger servern när du startar den. Ett skript är en text med kommandon som servern kör i tur och ordning, utan att någon skriver dem. Du klistrar in det under Advanced details i guiden Launch instances. (AWS: Run commands with user data)

Första raden ska vara #!/bin/bash. Den säger att programmet bash läser kommandona, samma program som tar emot det du skriver i en terminal. (AWS: User data and shell scripts)

Servern blir AMI plus user data. AMI:n ger operativsystemet. Skriptet lägger till resten, t.ex. installerar en webbserver och skriver en webbsida. (AWS: Customized cloud-init, kursens lektion sida 37)

När skriptet körs

Skriptet körs en gång, vid serverns första start. Startar du om servern körs det inte igen. (AWS: User data and shell scripts, kursens lektion sida 14)

Skriptet körs som root, administratören på servern. Det är inte root user i ditt AWS-konto. Starten tar några minuter extra medan skriptet körs. (AWS: User data and shell scripts)

Var du ser om det gick fel

Du ser det i loggen /var/log/cloud-init-output.log på servern. En logg är en fil där servern skriver vad som hände. cloud-init är programmet i Amazon Linux som kör user data, och det sparar allt skriptet skriver ut, även felmeddelanden. (AWS: User data and shell scripts, AWS: Customized cloud-init)

Öppna en terminal med EC2 Instance Connect och visa loggens sista 20 rader. sudo betyder att kommandot körs som root. Valfritt att prova:

sudo tail -n 20 /var/log/cloud-init-output.log

Quiz

1. Servern har gått i flera dagar och du startar om den. Vad händer med user data-skriptet?

2. Webbsidan som skriptet skulle skriva syns inte. Var letar du först?

3. Repetition från lektion 30: vad ger AMI:n servern, innan user data körs?

Sammanfattning

  • User data är ett skript du ger servern under Advanced details när du startar den. Första raden är #!/bin/bash.
  • Servern är AMI plus user data: AMI:n ger operativsystemet, skriptet installerar resten.
  • Skriptet körs en gång, vid första start, som root på servern. Inte vid omstart.
  • Gick något fel: läs /var/log/cloud-init-output.log i en terminal på servern.
