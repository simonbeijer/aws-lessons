Lektion 97

Händelse från API Gateway

Vad du ska veta efter lektionen Var metoden, sökvägen, id:t och kroppen står i eventet från API Gateway, och att body är en sträng där citattecknen inuti måste escapas.

Vad skickar API Gateway?

API Gateway skickar hela HTTP-anropet, som ett event i JSON. Tjänsten från lektion 70 tar emot anrop över HTTPS och kan skicka dem vidare till en Lambda-funktion. Då gör den om anropet till ett event, som handlern får. (AWS: Lambda med API Gateway, AWS: Payload format structure)

Var står delarna?

Delarna står på fasta platser i eventet. Koden behöver fyra av dem, här för anropet PUT /customers/abc-123: (AWS: Payload format structure)

DelI kodenVärde
Metodenevent.requestContext.http.method"PUT"
Sökvägenevent.rawPath"/customers/abc-123"
Id:tevent.pathParameters.id"abc-123"
Kroppenevent.body"{\"name\":\"Carol\"}"

Id:t finns där för att routen i API Gateway skrivs PUT /customers/{id}. Klammerparenteserna gör id till en sökvägsparameter, som :id i Express. (AWS: Path variables) Det riktiga eventet har fler fält. En testhändelse behöver bara dessa:

{
  "rawPath": "/customers/abc-123",
  "requestContext": { "http": { "method": "PUT" } },
  "pathParameters": { "id": "abc-123" },
  "body": "{\"name\":\"Carol\"}"
}

Varför escapas citattecknen?

Det beror på att body är en sträng, text inom dubbla citattecken, och kroppen inuti är JSON med egna citattecken. Ett vanligt " inuti avslutar strängen för tidigt, och då är testhändelsen inte JSON. Därför skrivs varje citattecken inuti som \", med ett omvänt snedstreck före. Det kallas att escapa tecknet. (RFC 8259: Strings)

"body": "{\"name\":\"Carol\"}"

Rätt. Strängen slutar vid sista citattecknet.

"body": "{"name":"Carol"}"

Fel. Strängen slutar redan före name.

Koden gör om strängen till ett objekt med JSON.parse(event.body). (MDN: JSON.parse())

Quiz

1. Anropet är PUT /customers/abc-123. Var står metoden PUT i eventet?

2. Kroppen ska vara {"name":"Carol"}. Vilken rad i testhändelsen är rätt?

3. Repetition från lektion 81: vem bestämmer vad eventet innehåller?

Sammanfattning

  • API Gateway gör om HTTP-anropet till ett event i JSON och ger det till handlern.
  • Metoden står i event.requestContext.http.method, sökvägen i event.rawPath, id:t i event.pathParameters.id och kroppen i event.body.
  • body är en sträng. Citattecknen inuti skrivs \", och koden gör om strängen till ett objekt med JSON.parse.
