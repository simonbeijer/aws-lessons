Lektion 98

Svar till API Gateway

Vad du ska veta efter lektionen Att svaret är ett objekt med statusCode, headers och body som sträng, och att ett fel som inte fångas ger klienten ett 5xx-fel med bara ett kort meddelande.

Vad returnerar handlern?

Handlern returnerar ett objekt med tre delar: statusCode, headers och body. API Gateway gör om det till HTTP-svaret som klienten får. (AWS: Lambda function response for format 2.0)

return {
  statusCode: 404,
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ error: "customer 999 not found" })
};
DelBlir i svaret
statusCodeStatuskoden, här 404.
headersHeaders, här Content-Type.
bodyKroppen, alltid en sträng.

I Express skrev res.status(404).json(...) svaret. Här returnerar handlern det.

Varför är body en sträng?

Kroppen i ett HTTP-svar är text. JSON.stringify gör om ett objekt till en sträng med JSON, det omvända mot JSON.parse i lektion 97. (MDN: JSON.stringify())

I konsolens testresultat syns citattecknen escapade:

"body": "{\"error\":\"customer 999 not found\"}"

Alla svar har samma form, och body är alltid en sträng.

Vad händer vid fel?

Klienten får ett 5xx-fel och bara {"message":"Internal Server Error"}. Det gäller ett kastat fel som inget fångar. (AWS: HTTP API Internal Server Error, AWS: Handling Lambda errors)

Att kasta ett fel, throw, stoppar koden direkt. Ett try/catch runt koden kan fånga felet och returnera ett eget svar, till exempel 404. Fångas felet inte, blir det inget svar från handlern. (MDN: throw)

Detaljerna hamnar bara i CloudWatch Logs.

500 eller 502?

Kursmaterialet säger 500. AWS felsida för Lambda säger 502 när funktionen kastar ett fel eller svarar i fel format. API Gateways felsökningssida anger ingen kod. Vilken som gäller är obekräftat. (AWS: Handling Lambda errors with API Gateway, AWS: HTTP API Internal Server Error)

Sammanfattning

  • Handlern returnerar ett objekt med statusCode, headers och body, och API Gateway gör om det till HTTP-svaret.
  • body är alltid en sträng. JSON.stringify gör om ett objekt till JSON-text.
  • Ett fel som inte fångas ger klienten ett 5xx-fel och bara Internal Server Error. Detaljerna finns i CloudWatch Logs.
