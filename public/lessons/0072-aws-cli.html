Lektion 72

AWS CLI

Vad du ska veta efter lektionen Hur ett kommando som aws elbv2 create-load-balancer --region eu-north-1 är byggt: tjänst, åtgärd och flaggor. Och vad --query och --output text gör med svaret.

Vad är AWS CLI?

AWS CLI är programmet aws. Med det styr du AWS med kommandon i en terminal, i stället för att klicka i konsolen. (AWS: What is the AWS CLI?)

I CloudShell finns aws redan, inloggat som samma IAM user som i konsolen. (AWS: CLI in CloudShell)

Hur är ett kommando byggt?

Delarna kommer alltid i samma ordning: aws, tjänst, åtgärd och flaggor. (AWS: Command structure)

DelI exempletVad den gör
ProgramawsStartar AWS CLI.
Tjänstelbv2Tjänsten, här Elastic Load Balancing: lastbalanserare. (AWS: What is ELB?)
Åtgärdcreate-load-balancerVad tjänsten ska göra: skapa en lastbalanserare.
Flagga--region eu-north-1Skickar just det här kommandot till Europe (Stockholm).

Flaggorna börjar med -- och får stå i vilken ordning som helst efter åtgärden. (AWS: Command line options)

Vad gör --query och --output?

--query väljer ut den del av svaret du vill ha, och --output text skriver den som vanlig text. Utan dem kommer hela svaret som JSON. (AWS: Filtering output, AWS: Output format)

aws ec2 describe-subnets \
  --region eu-north-1 \
  --query 'Subnets[].SubnetId' \
  --output text

Åtgärden describe-subnets visar dina subnät. Subnets[].SubnetId betyder: ta SubnetId från varje subnät i listan Subnets. Ett \ sist på raden betyder att kommandot fortsätter, som i curl. (Bash: Escape Character)

JSON med alla fält för varje subnät (här förkortat):

{
    "Subnets": [
        {
            "AvailabilityZone": "eu-north-1a",
            "CidrBlock": "172.31.16.0/20",
            "SubnetId": "subnet-0a1b2c3d4e5f60001",
            ...

Fortfarande JSON, men bara id:na:

[
    "subnet-0a1b2c3d4e5f60001",
    "subnet-0a1b2c3d4e5f60002"
]

Bara id:na, som vanlig text:

subnet-0a1b2c3d4e5f60001	subnet-0a1b2c3d4e5f60002

Quiz

1. Vad säger elbv2 i aws elbv2 create-load-balancer?

2. Du kör describe-subnets med --query 'Subnets[].SubnetId' men utan --output text. Hur ser svaret ut?

3. Repetition från lektion 71: CloudShell står på Europe (Ireland). Du skapar något med --region eu-north-1. Var hamnar det?

Sammanfattning

  • AWS CLI är programmet aws. Det styr AWS med kommandon och finns redan i CloudShell.
  • Ett kommando är byggt som aws, tjänst, åtgärd och flaggor, till exempel aws elbv2 create-load-balancer --region eu-north-1.
  • --query väljer ut en del av svaret. --output text skriver den som vanlig text i stället för JSON.
