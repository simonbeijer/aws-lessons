Lektion 75

Application Load Balancer

Vad du ska veta efter lektionen Att en Application Load Balancer tar emot trafiken och fördelar den till servrarna bakom, att den kräver subnät i två zoner, och att ett nytt konto kan vara spärrat för den tills AWS Support hävt spärren.

Vad gör en lastbalanserare?

En Application Load Balancer, kort ALB, tar emot alla anrop och fördelar dem på servrarna bakom, till exempel EC2-instanser. Den som anropar ser bara ALB:n. (AWS: What is an Application Load Balancer?)

Den skickar bara anrop till servrar som svarar när den kollar dem. Application betyder att den hanterar HTTP-anrop. (AWS: How ELB works)

Varför två zoner?

För att trafiken ska komma fram även om en zon går ner. En ALB kräver därför subnät i minst två Availability Zones, ett per zon. (AWS: Subnets for your load balancer)

Anropen går till servrar i båda zonerna.

Alla anrop går till servrarna i eu-north-1b. (AWS: Availability Zones and nodes)

Därför får --subnets flera id:n, som i lektion 74.

Vad är kontospärren?

Vissa nya konton är spärrade för lastbalanserare. Felet blir:

This AWS account currently does not support creating load balancers.

Felet beror inte på ditt kommando. Bara AWS Support, AWS kundtjänst, kan häva spärren. Det kan ta dagar, så prova tidigt. (AWS re:Post)

Gör så här vid felet

Öppna Support Center i konsolen. Välj Create case, sedan Account and billing support, som inte kräver supportplan. (AWS: Contacting Support)

Ej bekräftat

Spärren beskrivs bara på forumet re:Post, inte i AWS dokumentation. Om ALB:ns timkostnad dras från Free plans krediter är oklart. (AWS: ELB pricing, AWS: Choosing a plan)

Quiz

1. Du får This AWS account currently does not support creating load balancers. Vad gör du?

2. Du anger bara ett subnät i --subnets. Vad händer?

3. Repetition från lektion 23: varför räcker inte två subnät i samma zon?

Sammanfattning

  • En ALB tar emot alla anrop och skickar varje anrop till en server bakom som svarar.
  • Den kräver subnät i minst två zoner, så att trafiken kommer fram även om en zon går ner.
  • Vissa nya konton får inte skapa lastbalanserare förrän AWS Support hävt spärren. Det kan ta dagar, så prova tidigt.
