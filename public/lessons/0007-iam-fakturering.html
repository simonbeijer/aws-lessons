Lektion 7

IAM-åtkomst till fakturering

Vad du ska veta efter lektionen Varför en IAM user får Access Denied i Billing tills root user har slagit på åtkomsten.

Vad är Billing?

Billing är AWS sidor om pengar: fakturor, krediter och budgetar. Den heter Billing and Cost Management och nås via kontonamnet uppe till höger i konsolen. (AWS: Activating access to the Billing console)

Som standard kan ingen IAM user öppna Billing. Den får Access Denied, ett felmeddelande som betyder att du saknar behörighet. (AWS: Granting access to your billing information)

Varför räcker inte AdministratorAccess?

För att Billing har två lås, och en policy öppnar bara det ena. (AWS: Granting access to your billing information)

Lås 1: Activate IAM Access

En inställning för hela kontot. Bara root user kan slå på den, och det görs en gång.

Lås 2: en policy

Policyn måste tillåta Billing. AdministratorAccess gör det, eftersom den tillåter allt.

Är lås 1 av får även en IAM user med AdministratorAccess Access Denied. (AWS: Activating access to the Billing console, AWS: Tasks that require root user credentials)

Var slår root på inställningen?

På sidan Account i Billing. Root user klickar på kontonamnet och väljer Account. Där finns avsnittet IAM User and Role Access to Billing Information (role är en annan sorts identitet, som kommer i en senare lektion). (AWS: Grant access to the billing console)

Gör så här

Som root user: Edit, markera Activate IAM Access, Update. Sidan: https://console.aws.amazon.com/billing/home#/account

Quiz

1. Du är IAM user med AdministratorAccess och får Access Denied i Billing. Varför?

2. Vem kan slå på Activate IAM Access?

3. Repetition från lektion 6: inställningen är på. En ny IAM user ligger inte i någon grupp. Kommer den in i Billing?

Sammanfattning

  • Som standard får alla IAM users Access Denied i Billing, även med AdministratorAccess.
  • Billing har två lås: inställningen Activate IAM Access och en policy som tillåter Billing. Båda måste vara öppna.
  • Bara root user kan slå på Activate IAM Access, en gång, under Account i Billing.
