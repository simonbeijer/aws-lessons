Lektion 3

MFA

Vad du ska veta efter lektionen Vad MFA är, och varför både root user och din IAM user ska ha det.

Vad är MFA?

MFA (multi-factor authentication) betyder att du loggar in med två saker: ditt lösenord och en kod från en MFA-enhet. (AWS: Multi-factor authentication in IAM)

MFA-enheten är oftast en authenticator-app i mobilen, en app som visar en sexsiffrig kod. Koden byts var 30:e sekund. Den som bara har ditt lösenord kommer alltså inte in. (AWS: Assign a virtual MFA device)

Varför MFA på root user?

För att root kan göra allt i kontot. Därför kräver AWS MFA på root user. Har du inte lagt till det, måste du göra det inom 35 dagar från första inloggningsförsöket i konsolen. (AWS: Root user best practices)

Varför MFA på IAM user också?

För att MFA på root bara skyddar root. Din IAM user har eget lösenord och egen MFA. Utan MFA räcker dess lösenord för att komma in. AWS rekommenderar MFA för både root och IAM users. (AWS: Multi-factor authentication in IAM)

Root user

E-post och lösenord + egen MFA-enhet. Kan göra allt

IAM user

Användarnamn och lösenord + egen MFA-enhet. Till vardags

Gör så här

Lägg båda i samma authenticator-app, som två poster med olika namn. De flesta appar klarar flera. (AWS)

Quiz

Sammanfattning

  • MFA betyder att du loggar in med lösenord och en kod från en MFA-enhet, oftast en authenticator-app i mobilen.
  • Root user kan göra allt, och AWS kräver MFA på root.
  • MFA på root skyddar bara root. Din IAM user behöver en egen MFA-enhet.
