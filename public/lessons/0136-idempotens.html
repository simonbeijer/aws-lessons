Lektion 136

Idempotens

Vad du ska veta efter lektionen Att idempotent betyder att samma meddelande två gånger ger samma resultat som en gång, och att if_not_exists(welcome_sent_at, :t) skriver tiden bara första gången.

Vad är idempotent?

Idempotent betyder att samma anrop, upprepat, ger samma effekt som ett enda. Lektion 49 visade det för HTTP-metoder. Här gäller det en funktion som får samma meddelande två gånger, vilket en standardkö kan ge: databasen ska se likadan ut efter andra körningen som efter första. (MDN: Idempotent)

Funktionen skriver tiden för välkomstmeddelandet i attributet welcome_sent_at. Med SET welcome_sent_at = :t skriver andra körningen över tiden med en ny. Då är funktionen inte idempotent. (AWS: Update expressions, SET)

Vad gör if_not_exists?

if_not_exists(path, value) ger value om attributet path saknas i itemet, annars det som redan står där. Den finns bara i SET i ett uttryck (update expression). (AWS: Update expressions, SET)

UpdateExpression: "SET welcome_sent_at = if_not_exists(welcome_sent_at, :t)"

Andra körningen skickar ett nytt :t, men attributet finns, så första tiden ligger kvar. Bara attributet är skyddat: en loggrad skrivs ändå två gånger, och ett mejl hade skickats två gånger.

Sammanfattning

  • Idempotent: samma meddelande två gånger ger samma resultat som en gång.
  • SET welcome_sent_at = if_not_exists(welcome_sent_at, :t) skriver tiden bara första gången. Loggrader och mejl skyddas inte av det.
