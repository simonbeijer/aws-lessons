CloudShell och AWS CLI

Kort sagt Hittills har allt i AWS (Amazon Web Services) gjorts genom att klicka i konsolen. Veckans första test görs i stället helt med kommandon, och senare anropas API:et med curl. Därför börjar veckan i CloudShell, en terminal i konsolen, och med AWS CLI (Command Line Interface), programmet som skickar kommandona.

Vad är CloudShell?

CloudShell är en terminal i webbläsaren som öppnas med ikonen >_ i menyraden i konsolen. Den körs hos AWS, inte på din Mac, och programmet aws finns redan installerat.

Du loggar inte heller in en gång till, för CloudShell använder inloggningen från konsolen. Loggade du in som din IAM user (Identity and Access Management), körs kommandona som den, med dess behörigheter.

Hur är ett kommando byggt?

Delarna kommer i samma ordning: aws, tjänst, åtgärd och flaggor. Så här listar du dina subnät:

aws ec2 describe-subnets --region eu-north-1
DelI exempletVad den gör
Tjänstec2Tjänsten, här EC2 (Elastic Compute Cloud).
Åtgärddescribe-subnetsVad den ska göra.
Flagga--region eu-north-1Skickar kommandot till Europe (Stockholm).

Flaggorna börjar med -- och får stå i vilken ordning som helst efter åtgärden. Utan --region gäller den region som konsolen stod på när du öppnade CloudShell. Kontrollera den först.

Vad gör --query och --output?

Svaret blir en lång JSON (JavaScript Object Notation) med alla fält. --query väljer ut den del du vill ha, och --output text skriver den som vanlig text.

aws ec2 describe-subnets \
  --region eu-north-1 \
  --query 'Subnets[].SubnetId' \
  --output text

Subnets[].SubnetId betyder: ta SubnetId från varje subnät i listan Subnets. Ett \ sist på raden betyder att kommandot fortsätter på nästa rad.

Alla fält (förkortat):

{
    "Subnets": [
        {
            "AvailabilityZone": "eu-north-1a",
            "CidrBlock": "172.31.16.0/20",
            "SubnetId": "subnet-0a1b2c3d4e5f60001",
            ...

Bara id:na, som JSON:

[
    "subnet-0a1b2c3d4e5f60001",
    "subnet-0a1b2c3d4e5f60002"
]

Som text:

subnet-0a1b2c3d4e5f60001	subnet-0a1b2c3d4e5f60002

Quiz

1. Du loggade in i konsolen som din IAM user och öppnar CloudShell. Som vem körs kommandona?

2. Du kör describe-subnets med --query 'Subnets[].SubnetId' men utan --output text. Hur ser svaret ut?

3. Konsolen står på Europe (Ireland). Du kör ett kommando i CloudShell med --region eu-north-1. Vart går det?

Sammanfattning

  • CloudShell öppnas med >_ i konsolen och är redan inloggad som din IAM user, med samma behörigheter. aws finns installerat.
  • Ett kommando är aws, tjänst, åtgärd och flaggor, till exempel aws ec2 describe-subnets --region eu-north-1.
  • Utan --region gäller konsolens region. --region väljer region för just det kommandot.
  • --query väljer ut en del av svaret. --output text skriver den som vanlig text i stället för JSON.
