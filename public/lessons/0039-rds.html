Lektion 39

RDS

Vad du ska veta efter lektionen Att RDS är en managed databas: vad AWS sköter och vad du sköter.

Vad är RDS?

RDS (Amazon Relational Database Service) är en databas som AWS kör åt dig. Managed betyder att AWS sköter driften, och du använder databasen. (AWS: What is Amazon RDS?)

En databas är ett program som sparar data, så att andra program, till exempel webbservern, kan läsa och skriva i den. En relationsdatabas sparar datan i tabeller med rader och kolumner. (AWS: What is a relational database?)

Databasprogrammet kallas motor, engine på engelska. Kursen använder PostgreSQL. Du väljer det under Engine options när du skapar databasen. (AWS: DB engines)

Vad AWS sköter och vad du sköter

AWS sköter motorn, patchar och backup. Du sköter schema, användare och security group. (kursens lektion sida 14, AWS: Comparison of responsibilities)

AWS

Installerar motorn. Patchar operativsystemet och motorn, alltså uppdaterar dem så att fel och säkerhetshål rättas. Tar backup, en kopia som databasen kan återställas från.

Du

Schemat: vilka tabeller och kolumner som finns. Datan. Användarna: inloggningar i själva databasen, inte IAM users. Security group: vem som får ansluta.

(AWS: Security in Amazon RDS, AWS: Comparison of responsibilities)

Skillnaden mot en databas på EC2

Installerar du PostgreSQL själv på en EC2-instans är operativsystemet, motorn, patcharna och backupen ditt ansvar. AWS sköter bara maskinerna och datacentret. (AWS: Comparison of responsibilities)

Det är Shared Responsibility Model: hur mycket som är ditt beror på tjänsten. Med RDS tar AWS en större del. (AWS: Security in Amazon RDS)

Sammanfattning

  • RDS är en managed databas: AWS kör den, och du använder den. Databasprogrammet kallas motor, i kursen PostgreSQL.
  • AWS sköter motorn, patchar och backup. Du sköter schema, användare och security group.
  • Kör du databasen på EC2 är operativsystem, motor, patchar och backup ditt ansvar. Det är Shared Responsibility Model.
