Lektion 79

Runtime

Vad du ska veta efter lektionen Att runtime är språket och versionen funktionen körs i, till exempel Node.js 22.x, och att den styr vad som redan finns installerat.

Vad är en runtime?

En runtime är språket och versionen som Lambda kör din kod i, till exempel Node.js 22.x. Du väljer den under Runtime när du skapar funktionen. Senare ändrar du den under Runtime settings på funktionens sida. (AWS: Lambda runtimes)

På din server körde du koden med node server.js, och Node.js fanns installerat där. I Lambda har AWS redan installerat Node.js åt dig. Du väljer bara vilken version.

Vilken version ska du välja?

Välj den senaste Node.js-version som konsolen föreslår, 22.x eller nyare. Lambda stöder nu Node.js 22.x och 24.x. Node.js 26.x är en förhandsversion och ska inte användas på riktigt. (AWS: Building with Node.js)

Äldre versioner, som Node.js 20, stöder AWS inte längre. Dem kan du inte välja i konsolen. (AWS: Runtime use after deprecation)

Vad finns redan installerat?

Runtime bestämmer vilka paket, alltså färdig kod, som redan finns när funktionen körs. I Node.js-runtime finns AWS SDK, färdig kod för att prata med andra AWS-tjänster. Därför behövs ingen npm install när du skriver koden i konsolens editor. (AWS: Runtime-included SDK versions)

Andra paket, som Express, finns inte. Dem måste du skicka med koden själv. (AWS: Lambda runtimes)

Varning

Står det Cannot find package i felet och paketet hör till AWS SDK: kontrollera runtime under Runtime settings. Byt till Node.js 22.x eller nyare.
