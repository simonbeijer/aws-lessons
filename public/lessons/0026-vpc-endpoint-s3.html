Lektion 26

VPC endpoint (S3 Gateway)

Vad du ska veta efter lektionen Varför den privata route tablen har en rad för S3, och att gateway-endpointen inte kostar något.

Vad är en VPC endpoint?

En VPC endpoint är en väg från din VPC direkt till en AWS-tjänst, utan Internet Gateway. Kursens VPC får en gateway endpoint för S3, tjänsten som lagrar filer som objekt i buckets. En gateway endpoint är den sort som trafiken når via en rad i route tablen. (AWS: Gateway endpoints, AWS: Gateway endpoints for Amazon S3)

Den fungerar bara mot S3 i samma region som VPC:n, alltså eu-north-1. (AWS: Gateway endpoints for Amazon S3)

Varför har den privata route tablen en rad för S3?

Raden skickar trafik till S3 via endpointen. Utan den når de privata subnäten inte S3 alls, eftersom de saknar raden till internet. (AWS: Gateway endpoints, Overview)

Vad kostar den?

Ingenting. Gateway endpoints har ingen avgift. (AWS: Gateway endpoints)

Det finns en annan sort, interface endpoint, som kostar. Kursen använder den inte. (AWS: Gateway endpoints for Amazon S3)

Sammanfattning

  • En VPC endpoint är en väg från VPC:n direkt till en AWS-tjänst, utan Internet Gateway. Kursens gateway endpoint går till S3 i samma region.
  • Raden pl-... → vpce-... i den privata route tablen skickar S3-trafik till endpointen. Utan den når de privata subnäten inte S3.
  • En gateway endpoint kostar ingenting.
