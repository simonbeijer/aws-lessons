Lektion 66

Swagger UI

Vad du ska veta efter lektionen Att Swagger UI ritar en webbsida ur OpenAPI-filen där varje anrop går att prova, och att alla som når sidan ser hela API:et.

Vad är Swagger UI?

Swagger UI är ett verktyg som läser en OpenAPI-fil och ritar en webbsida ur den. Varje anrop, till exempel GET /customers, blir en rad du fäller ut, med kroppen det tar och svaren det ger. (Swagger UI, kursmaterialet v41)

Ändrar du filen och startar om servern, ändras sidan. (kursmaterialet v41)

I Express serverar paketet swagger-ui-express, färdig kod som installeras med npm, sidan på en sökväg du väljer, här /docs. (swagger-ui-express, kursmaterialet v41)

Hur provar man ett anrop?

Fäll ut anropet, klicka Try it out, fyll i och klicka Execute. Webbläsaren skickar då anropet till API:et. Under knappen visas statuskoden, svaret och samma anrop som curl-kommando. (kursmaterialet v41)

Öppna sidan på samma adress och port som API:et, till exempel http://<publik IP>:3000/docs. Annars kan webbläsaren stoppa anropet, och Swagger UI visar Failed to fetch. (Swagger UI: CORS, kursmaterialet v41)

Varning

Execute skickar ett riktigt anrop. DELETE tar bort kunden i databasen på riktigt.

Vem ser sidan?

Alla som når porten. Släpper regeln för port 3000 in 0.0.0.0/0, kan vem som helst öppna /docs. (kursmaterialet v41)

Sidan visar varje anrop som står i filen, även de du inte tänkt visa. Den skyddar ingenting. (kursmaterialet v41)

En bokningsapp hade Swagger UI öppet på /docs. Där syntes ett anrop som gav ut bokningar utan inloggning. En utomstående hämtade 184 000 stycken. (kursens lektion sida 24–25)

Quiz

1. Var hämtar Swagger UI det som står på sidan?

2. Du fyller i id 7 för DELETE /customers/:id och klickar Execute. Vad händer?

3. Repetition från lektion 35: regeln för port 3000 har källan 0.0.0.0/0. Vem kan öppna /docs?

Sammanfattning

  • Swagger UI ritar en webbsida ur OpenAPI-filen. I Express serverar swagger-ui-express den, här på /docs.
  • Try it out och Execute skickar ett riktigt anrop och visar statuskod, svar och curl-kommando. Öppna sidan på samma adress och port som API:et.
  • Alla som når porten ser sidan och varje anrop i filen. Sidan skyddar ingenting.
