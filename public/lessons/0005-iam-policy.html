Lektion 5

IAM policy

Vad du ska veta efter lektionen Att en IAM policy är ett dokument som säger vad någon får göra, till exempel AdministratorAccess.

Vad är en IAM policy?

En IAM policy är ett dokument som säger vad någon får göra i AWS. Kopplar du en policy till en IAM user får den behörigheten i dokumentet. (AWS: Policies and permissions in IAM)

Utan policy får en ny IAM user inte göra något. (AWS: IAM users and permissions)

Hur ser AdministratorAccess ut?

Som ett kort JSON-dokument med en enda regel: tillåt allt. JSON är ett textformat med namn och värden. (AWS: AdministratorAccess)

{
  "Version" : "2012-10-17",
  "Statement" : [
    {
      "Effect" : "Allow",
      "Action" : "*",
      "Resource" : "*"
    }
  ]
}

Klicka på ett namn för att se vad det betyder. (AWS: JSON policy document structure, AWS: Version)

Vilken version av policyspråket som används. Använd alltid den nuvarande, 2012-10-17.

Listan med regler. Varje regel står inom { }.

Allow betyder tillåt. Det andra värdet är Deny, neka.

Vilka handlingar regeln gäller, till exempel att skapa en IAM user. * betyder alla handlingar.

Vilka resurser regeln gäller. En resurs är något du har skapat i AWS, till exempel en IAM user. * betyder alla resurser.

Vem har skrivit den?

AWS. AdministratorAccess är en AWS managed policy: AWS skapar och sköter den, och du kan inte ändra den. Du hittar den i IAM, under Policies i vänstermenyn. (AWS: AWS managed policies, AWS: Adding IAM identity permissions)

Du kan också skriva egna policyer som bara ger det som behövs. AWS rekommenderar AdministratorAccess bara för kontots administratör. (AWS: AWS managed policies)

Sammanfattning

  • En IAM policy är ett dokument som säger vad någon får göra. Kopplar du den till en IAM user får den behörigheten.
  • AdministratorAccess säger Allow på alla handlingar (Action) och alla resurser (Resource). Det ger full tillgång.
  • AdministratorAccess är en AWS managed policy. AWS har skrivit den och du kan inte ändra den.
