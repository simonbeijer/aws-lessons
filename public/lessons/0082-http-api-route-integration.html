Hur når ett anrop funktionen?

Kort sagt Funktionen kan spara en kund, men ingen utanför AWS kan anropa den. Ett HTTP API (Hypertext Transfer Protocol, Application Programming Interface) i API Gateway tar emot anropet, väljer vad det gäller och skickar det till funktionen. Svaret går tillbaka samma väg.

Vad gör API Gateway?

Funktionen har ingen egen webbadress, så API Gateway står framför den. I lektion 70 gav den ett API en HTTPS-adress (HTTP med kryptering).

Här används ett HTTP API, en av API-typerna i API Gateway. REST API (Representational State Transfer) har fler funktioner och kostar mer per anrop, men de behövs inte här.

Ett anrop, till exempel PUT /customers/abc-123, går så här:

  1. API Gateway matchar det mot en route.
  2. Det skickas till routens integration, här funktionen, som ett event som handlern får.
  3. Det handlern returnerar görs om till ett HTTP-svar.

Vad är en route?

En route är metod plus sökväg. Den ligger i API Gateway, inte i koden som i Express. API:et får fem routes:

GET    /customers
POST   /customers
GET    /customers/{id}
PUT    /customers/{id}
DELETE /customers/{id}

Klammerparenteserna gör id till en sökvägsparameter. Anropet GET /customers/abc-123 matchar den tredje routen, och koden får abc-123 i pathParameters.id.

Matchar ingen route svarar API Gateway själv med 404 och {"message":"Not Found"}. Funktionen körs inte, så anropet syns inte i dess logg. Koden kan också svara 404 när kunden saknas, och kroppen visar vem som svarade.

Vad är en integration?

Integrationen är det som står bakom routen. Här är det funktionen, för alla fem routes. Det kan i stället vara en server, som API:et på EC2 (Elastic Compute Cloud) i lektion 70.

Adressen hör till API:et. Byter du integration anropar klienten samma adress.

Eventets innehåll och svarets form kommer i nästa lektion.

Quiz

1. GET /products får 404 med {"message":"Not Found"}. Vad har hänt?

2. Routen är GET /customers/{id}. Var hamnar abc-123 i anropet GET /customers/abc-123?

3. Repetition från lektion 57: vad svarar Express om ingen route matchar?

Sammanfattning

  • API Gateway matchar anropet mot en route, skickar det till integrationen (funktionen) och gör om svaret till HTTP.
  • En route är metod plus sökväg. {id} blir event.pathParameters.id.
  • Ingen matchande route ger 404 med {"message":"Not Found"} från API Gateway. Funktionen körs inte.
  • Adressen hör till API:et. Byter du integration ändras den inte.
