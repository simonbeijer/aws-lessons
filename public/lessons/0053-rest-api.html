Lektion 53

REST-API

Vad du ska veta efter lektionen Att ett REST-API lägger resursen i sökvägen, t.ex. /customers/42, och verbet i metoden, och att det vid fel svarar med en statuskod som säger vad som var fel.

Vad är ett REST-API?

Ett REST-API är en server som andra program anropar över HTTP, byggd efter reglerna i REST. API är de anrop servern svarar på, t.ex. hämta kund 42. REST är ett vanligt sätt att forma dem. (kursens lektion sida 2, MDN: API, MDN: REST)

I REST står resursen i sökvägen. Sökvägen är delen av adressen efter porten. I http://16.170.12.34:3000/customers/42 är sökvägen /customers/42. Det är samma text som efter metoden på startraden. (kursens lektion sida 11 och 14)

Substantiv i sökvägen, verb i metoden

Sökvägen säger vilken sak anropet gäller: ett substantiv. Metoden är verbet: vad som ska göras. Fem anrop för kunder, men bara två sökvägar: (kursens lektion sida 36, kursmaterialet v41, Microsoft: Web API design)

AnropGör
GET /customersHämtar alla kunder.
GET /customers/42Hämtar kund 42.
POST /customersSkapar en kund.
PUT /customers/42Ersätter kund 42.
DELETE /customers/42Tar bort kund 42.

Ett verb i sökvägen, som /deleteCustomer/42, bryter mot REST. Metoden säger redan vad som ska göras. (Microsoft: Web API design)

Rätt statuskod vid fel

Vid fel svarar ett REST-API med en statuskod som säger vad som var fel, och ett felmeddelande i JSON: 404 om resursen inte finns, 400 om anropet är fel. Klicka och jämför: (kursens lektion sida 13 och 36, kursmaterialet v41, Microsoft: Web API design)

404 Not Found
{"error":"customer 999 not found"}

Anropet är rätt, men kund 999 finns inte.

400 Bad Request
{"error":"id must be a positive integer, got \"abc\""}

Anropet är fel: abc kan aldrig vara ett kundnummer.

Quiz

1. Du vill ta bort kund 7. Vilket anrop följer REST?

2. GET /customers/abc ger 400, men GET /customers/999 ger 404. Varför?

3. Repetition från lektion 49: samma DELETE /customers/42 skickas två gånger. Hur ser det ut efter andra anropet?

Sammanfattning

  • Ett REST-API är en server som andra program anropar över HTTP, byggd efter reglerna i REST.
  • Resursen står i sökvägen, delen av adressen efter porten, t.ex. /customers/42. Verbet står i metoden. Inga verb i sökvägen.
  • Vid fel svarar API:et med rätt statuskod och ett felmeddelande i JSON: 404 när resursen inte finns, 400 när anropet är fel.
