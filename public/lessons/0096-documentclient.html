Lektion 96

DocumentClient

Vad du ska veta efter lektionen Att DynamoDBDocumentClient låter dig skicka vanliga JavaScript-objekt till DynamoDB i stället för att skriva varje värde som { "S": "Alice" }.

Hur vill DynamoDB ha värdena?

DynamoDB, databastjänsten från lektion 88, vill ha en typ runt varje värde. Den tar emot JSON. Varje värde ligger i ett eget objekt, där namnet är en bokstav som säger typen: S för text (String), N för tal (Number). Namnet Alice skrivs { "S": "Alice" }. Även tal skickas som text: { "N": "34" }. (AWS: Data type descriptors)

Vad gör DocumentClient?

DocumentClient skriver typerna åt dig. DynamoDBDocumentClient är en klient ur paketet @aws-sdk/lib-dynamodb. Du ger den ett vanligt JavaScript-objekt, par av namn och värde inom { } som ett JSON-objekt. Klienten lägger till S, N och de andra typerna innan anropet skickas. Svaret översätts tillbaka, så du får vanliga objekt ut också. (AWS: DynamoDB document client, AWS SDK: lib-dynamodb README)

{ id: "demo-1", name: "Alice" }

Ett vanligt objekt. I JavaScript behövs inga citattecken runt namnen. Klienten lägger till typerna.

{ id: { S: "demo-1" }, name: { S: "Alice" } }

Samma data. Du skriver typen runt varje värde själv.

Hur skapas den?

Den skapas av en vanlig DynamoDBClient. DynamoDBDocumentClient.from tar klienten från lektion 95 och lägger DocumentClient runt den. Kommandona hämtas ur samma paket, till exempel PutCommand, som sparar ett item, som PutItem. (AWS: DynamoDB document client)

import { DynamoDBClient } from "@aws-sdk/client-dynamodb";
import { DynamoDBDocumentClient, PutCommand } from "@aws-sdk/lib-dynamodb";

const db = DynamoDBDocumentClient.from(new DynamoDBClient({})); // en gång per miljö

export const handler = async (event) => {
  await db.send(new PutCommand({
    TableName: "v42-customers",              // tabellens namn
    Item: { id: "demo-1", name: "Alice" },   // itemet som sparas
  }));
};

Sammanfattning

  • DynamoDB vill ha en typ runt varje värde, till exempel { "S": "Alice" } för text och { "N": "34" } för tal.
  • DynamoDBDocumentClient låter dig skicka vanliga JavaScript-objekt. Den lägger till typerna innan anropet och tar bort dem ur svaret.
  • Den skapas med DynamoDBDocumentClient.from(new DynamoDBClient({})), och kommandona som PutCommand hämtas ur @aws-sdk/lib-dynamodb.
