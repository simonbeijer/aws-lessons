Handler och event

Kort sagt Förra lektionen sa att Lambda kör din kod när en händelse kommer. Den här visar var koden börjar och vad den får in: handlern tar emot det anroparen skickar och lämnar tillbaka svaret. Innan något annat anropar funktionen kan du själv vara anroparen, med en testhändelse.

Vad är en handler?

Handlern är den funktion i koden som Lambda anropar varje gång en händelse kommer. Så här ser en ut:

export const handler = async (event, context) => {
  return { message: "Hej!" };
};

Den får in två saker. event är händelsen, alltså det anroparen skickar med. context är information om själva anropet. Det handlern returnerar blir svaret till anroparen. I Express skickade du svaret med res.json. Här returnerar du det.

export gör att Lambda utanför filen kan anropa funktionen. async låter den vänta på annat, till exempel en annan AWS-tjänst (Amazon Web Services).

Hur hittar Lambda den?

Inställningen Handler under Runtime settings pekar ut den: index.handler betyder funktionen handler i filen index.mjs.

Varning

Byter du namn på filen eller funktionen hittar Lambda inte handlern. Felet heter Runtime.HandlerNotFound. Ändra tillbaka, eller ändra Handler så att den stämmer.

Hur skriver man ett event?

Ett event är JSON (JavaScript Object Notation). Med eventet { "name": "Alice" } ger event.name värdet "Alice".

En testhändelse är ett event du själv skriver, så att du är anroparen. I konsolen står en Test-knapp i editorn. Man ger händelsen namn under Event name och skriver JSON i rutan Event JSON. Save sparar den, Test kör funktionen med den som event och visar svaret. Behöver funktionen ingen indata räcker {}.

Sparade händelser körs igen med ett klick, upp till 10 per funktion som bara du ser. Utan Save försvinner händelsen när man lämnar konsolen.

Quiz

1. Inställningen Handler är index.handler. Vad pekar den på?

2. Testhändelsen är { "name": "Alice" }. Handlern slutar med return event.name;. Vad blir svaret?

3. Du ändrar texten i return i editorn och klickar Test. Svaret är det gamla. Varför?

Sammanfattning

  • Handlern är funktionen Lambda anropar. index.handler är funktionen handler i index.mjs. Stämmer inte namnen blir felet Runtime.HandlerNotFound.
  • Handlern får event (det anroparen skickar med) och context (information om anropet). Det den returnerar blir svaret.
  • Ett event är JSON, och event.name ger värdet för name.
  • En testhändelse är ett event du skriver själv. {} räcker utan indata. Upp till 10 sparas per funktion.
