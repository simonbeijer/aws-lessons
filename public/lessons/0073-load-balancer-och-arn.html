Application Load Balancer och ARN

Kort sagt En lastbalanserare tar emot trafik och fördelar den på flera servrar. Vecka 45 behöver en, men ett nytt konto kan vara spärrat i dagar, så kontot testas redan nu med kommandon. Svaret när den skapas är dess ARN (Amazon Resource Name), och det behövs för att ta bort den igen.

Vad gör en lastbalanserare?

En Application Load Balancer (ALB) står framför flera servrar: den tar emot alla anrop och skickar varje till en server bakom som svarar. Application betyder att den hanterar HTTP-anrop.

Den kräver subnät i minst två Availability Zones, så att trafiken kommer fram även om en zon går ner. Testet tar subnäten i kontots default VPC (Virtual Private Cloud), med ett subnät per zon. aws elbv2 create-load-balancer får dem från $SUBNETS. elbv2 är Elastic Load Balancing version 2.

Lastbalanseraren kostar så länge den finns, så testet tar bort den direkt. Men vissa nya konton är spärrade, och då blir felet:

This AWS account currently does not support creating load balancers.

Bara AWS Support kan häva spärren, och det kan ta dagar. Öppna Support Center, välj Create case och sedan Account and billing support, som inte kräver supportplan.

Ej bekräftat

Spärren beskrivs bara på forumet re:Post.

Vad är ARN:et?

Lyckas skapandet svarar AWS med ARN:et, lastbalanserarens fullständiga namn. Det pekar ut exakt en resurs bland alla konton och regioner. Borttagningen kräver det, inte namnet, så det sparas med $(...).

arn:aws:elasticloadbalancing:eu-north-1:123456789012:loadbalancer/app/v42-lb-test/50dc6c495c0c9188

Efter arn:aws: kommer fyra delar:

Tjänsten som resursen hör till.

Regionen där resursen finns, här Stockholm.

Kontonumret, tolv siffror. I ditt ARN står ditt eget.

Typen loadbalancer/app, sedan namnet och ett id som AWS ger den.

Samma form står i Resource i en bucket policy, och senare i veckan för en DynamoDB-tabell: arn:aws:dynamodb:eu-north-1:123456789012:table/namn.

Sammanfattning

  • En ALB tar emot alla anrop och skickar varje till en server bakom som svarar. Den kräver subnät i minst två zoner, och testet tar dem från default VPC.
  • Lastbalanseraren kostar så länge den finns, så testet tar bort den direkt.
  • Vissa nya konton är spärrade tills AWS Support hävt det. Det kan ta dagar, så prova tidigt.
  • Ett ARN pekar ut exakt en resurs: arn:aws:, tjänst, region, konto, resurs. Det får du tillbaka vid skapandet, och det behövs för att ta bort och i Resource.
