Lektion 36

EC2 Instance Connect

Vad du ska veta efter lektionen Hur du får en terminal på servern i webbläsaren via SSH, utan key pair, och vad som måste vara på plats för att det ska fungera.

Vad är EC2 Instance Connect?

EC2 Instance Connect är en AWS-tjänst som ger dig en terminal på servern i webbläsaren. En terminal är ett fönster där du skriver kommandon och servern svarar med text. (AWS: Connect using the EC2 console)

Anslutningen går över SSH på port 22. Tjänsten kostar inget utöver servern. Servern behöver en AMI med tjänsten installerad, som Amazon Linux 2023. (AWS: EC2 Instance Connect, AWS: Install EC2 Instance Connect)

Varför inget key pair behövs

Ett key pair är två nycklar: en publik på servern och en privat på din dator. Tappar du den privata går den inte att få tillbaka. (AWS: Key pairs)

Med Instance Connect lägger AWS en ny publik nyckel på servern vid varje anslutning, i 60 sekunder. En IAM policy avgör om du får göra det. Därför väljer du Proceed without a key pair i guiden Launch instances. (AWS: EC2 Instance Connect)

Vad som måste vara på plats

Servern måste nås från internet: route till Internet Gateway och publik IP-adress (lektion 34). Regeln för port 22 ska ha prefix list för EC2 Instance Connect som källa, inte alla adresser. Trafiken kommer från tjänsten, inte från din dator. (AWS: Prerequisites, kursens lektion sida 13)

Anslut i EC2-konsolen: (AWS: Connect using the EC2 console)

  1. Markera servern och klicka Connect.
  2. Välj fliken EC2 Instance Connect.
  3. Användarnamnet ska vara ec2-user, standardanvändaren i Amazon Linux.
  4. Klicka Connect. Terminalen öppnas.

Sammanfattning

  • EC2 Instance Connect ger en terminal på servern i webbläsaren, över SSH på port 22. Den kostar inget utöver servern.
  • Inget key pair behövs: AWS lägger en ny publik nyckel på servern vid varje anslutning, i 60 sekunder.
  • Servern behöver en AMI med tjänsten, route till Internet Gateway och publik IP-adress.
  • Port 22 öppnas bara för prefix list för EC2 Instance Connect, inte för alla.
  • Anslut med Connect, fliken EC2 Instance Connect och användaren ec2-user.
