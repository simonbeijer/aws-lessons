Vad står mellan klienten och funktionen?

Kort sagt Funktionen kan nu svara, men en klient måste först hitta den, få komma in och inte skicka för många anrop. Tre saker ordnar det: en adress, en regel om vem som får anropa, och en gräns för hur många.

Vilken adress anropar klienten?

Adressen kommer från en stage. En stage är en driftsatt version av routes och integrationer i ett API (Application Programming Interface), med en egen adress, Invoke URL. URL står för Uniform Resource Locator. Ett nytt API får stagen $default. Den har auto-deploy: en ändrad route gäller direkt, men funktionens kod först efter Deploy i Lambda.

För $default står routen direkt efter .amazonaws.com: https://ab12cd34ef.execute-api.eu-north-1.amazonaws.com/customers. Andra stages, som prod, står före routen. Skriver du /$default svarar API Gateway Forbidden.

Vem får anropa funktionen?

Adressen räcker inte: API Gateway måste också få köra funktionen. Det styr en resource-based policy, en policy som sitter på själva funktionen, som en bucket policy.

Regeln ger tjänsten apigateway.amazonaws.com rätt att göra lambda:InvokeFunction, bara från ditt API. Konsolen lägger till den åt dig. Saknas den körs funktionen aldrig, och klienten får ett 5xx-fel.

Rollen är något annat: execution role säger vad funktionen får göra, policyn på funktionen vem som får köra den.

Hur många anrop släpps in?

Throttling är en gräns för anrop per sekund, satt på stagen. Varje anrop tar en pollett ur en hink. Burst är hur många polletter hinken rymmer, alltså anrop på en gång. Rate är hur många som fylls på per sekund.

Är hinken tom svarar API Gateway 429 Too Many Requests, en 4xx. Funktionen körs inte, så gränsen skyddar den och DynamoDB bakom. Den gäller alla klienter tillsammans.

Sammanfattning

  • En stage är en driftsatt version av API:et med egen Invoke URL. $default har inget namn i adressen och har auto-deploy. Funktionens kod gäller först efter Deploy i Lambda.
  • Resource-based policy på funktionen säger vem som får anropa den: apigateway.amazonaws.com med lambda:InvokeFunction. Rollen säger vad funktionen får göra. Saknas regeln får klienten Internal Server Error.
  • Rate är anrop per sekund i längden, burst är anrop på en gång. Över gränsen svarar API Gateway 429 utan att köra funktionen. Gränsen gäller alla klienter tillsammans.
