Lektion 51

Header

Vad du ska veta efter lektionen Att en header är en rad med nyckel och värde om anropet eller svaret, och att servern inte läser kroppen om anropet saknar Content-Type: application/json.

Vad är en header?

En header är en rad med en nyckel, ett kolon och ett värde. I Content-Type: application/json är Content-Type nyckeln och application/json värdet. (kursens lektion sida 11 och 14, MDN: HTTP headers)

Headers står mellan startraden och den tomma raden, en per rad. De säger något om meddelandet men är inte innehållet. Nyckeln får skrivas med små bokstäver: content-type är samma header. (MDN: HTTP headers)

Vilka headers har ett anrop och ett svar?

Exemplet skapar en kund och har fyra olika headers: (kursens lektion sida 14)

POST /customers HTTP/1.1
Host: 16.170.12.34:3000
Content-Type: application/json
Accept: application/json

{ "name": "Carol" }
HTTP/1.1 201 Created
Content-Type: application/json
Location: /customers/3

{ "id": 3, "name": "Carol" }
HeaderStår iSäger
HostAnropetVart anropet ska.
Content-TypeBådaVilket format kroppen har.
AcceptAnropetVilket format klienten vill ha tillbaka.
LocationSvaretVar den nya kunden finns.

application/json betyder att kroppen är skriven i formatet JSON. JSON är nästa lektion. (MDN: Content-Type, MDN: Accept, MDN: Location)

Vad händer om Content-Type saknas?

Kursens server läser kroppen bara när anropet har Content-Type: application/json. Saknas headern ser servern ingen kropp, fast den finns där. Klicka och jämför: (kursmaterialet v41, MDN: Content-Type)

POST /customers HTTP/1.1
Content-Type: application/json

{ "name": "Carol" }

Svar: 201 Created. Carol skapas.

POST /customers HTTP/1.1

{ "name": "Carol" }

Svar: 400 Bad Request och name is required.

Servern tror att namnet saknas. Det är en 4xx: felet ligger i anropet, och klienten rättar det genom att lägga till headern. Det är ett vanligt fel i klientkod. (kursmaterialet v41)

Quiz

1. Vad säger headern Accept: application/json?

2. Du skickar POST /customers med ett namn i kroppen men utan Content-Type. Vad svarar servern?

3. Repetition från lektion 50: anropet utan Content-Type fick 400. Vem ska rätta felet?

Sammanfattning

  • En header är en rad med nyckel och värde, t.ex. Content-Type: application/json. Den står mellan startraden och den tomma raden.
  • Host säger vart anropet ska, Content-Type vilket format kroppen har, Accept vad klienten vill ha tillbaka och Location var en ny resurs finns.
  • Saknas Content-Type: application/json läser servern inte kroppen och svarar 400. Klienten rättar det med headern.

Källor

Huvudkälla: MDN: HTTP headers.

Om de enskilda headers: MDN: Content-Type, MDN: Accept och MDN: Location.
