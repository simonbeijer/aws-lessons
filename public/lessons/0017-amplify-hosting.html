Lektion 17

Amplify Hosting

Vad du ska veta efter lektionen Hur Amplify Hosting bygger och publicerar din app av sig själv varje gång du kör git push.

Vad är Amplify Hosting?

Amplify Hosting är en AWS-tjänst som hämtar din kod från ett Git-repo, bygger den och publicerar den på en webbadress. (AWS: Welcome to Amplify Hosting)

Ett Git-repo är en mapp med kod och alla sparade ändringar, här på GitHub. Amplify kopplas till en gren (branch), en egen linje av ändringar i repot, oftast main. (AWS: Connect a Git repository)

Amplify GitHub App installeras på GitHub och ger Amplify läsrätt till de repon du väljer. (AWS: Amplify access to GitHub)

Vad händer vid git push?

Varje ändring som når den kopplade grenen startar ett nytt bygge och en ny publicering. (AWS: Build configuration)

En commit är en sparad ändring i Git, på din dator.

git push skickar dina commits till repot på GitHub. Grenen main har nu ny kod.

Amplify kör npm run build på en maskin hos AWS. Byggkommandot hittar Amplify själv. (AWS: Build configuration)

Filerna i dist/ läggs ut på webbadressen. Den gamla versionen byts först när allt är klart. (AWS: Atomic deployments)

Var appen hamnar

Appen hamnar på en adress med grenens namn först: https://main.d1a2b3c4.amplifyapp.com. (AWS: Default domain)

Amplify Hosting

Amplify bygger vid varje push. HTTPS.

Konsolen ber också om en service role, behörighet för Amplify i ditt konto. (AWS: Confirm the build settings)

Sammanfattning

  • Amplify Hosting hämtar koden från en gren i ditt Git-repo, bygger den och publicerar den. Amplify GitHub App ger läsrätt till de repon du väljer.
  • Varje git push till den kopplade grenen startar ett nytt bygge och en ny publicering. Du gör inget i AWS-konsolen.
  • Appen hamnar på en HTTPS-adress som slutar på amplifyapp.com.
