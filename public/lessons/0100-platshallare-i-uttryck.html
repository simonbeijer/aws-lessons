Lektion 100

Platshållare i uttryck

Vad du ska veta efter lektionen Att #n står för ett attributnamn och :n för ett värde i SET #n = :n, och att name måste ha ett alias eftersom det är ett reserverat ord.

Vad är ett uttryck?

Ett uttryck är en kort text som säger vad DynamoDB ska göra med ett item. UpdateItem vill ha ett uttryck med attributet som ändras och dess nya värde. Det börjar med SET, som lägger till attributet eller skriver över det som finns. (AWS: Update expressions)

I koden skickas UpdateItem med UpdateCommand, från samma paket som PutCommand i lektion 96. (AWS SDK: DynamoDB utilities)

Vad står #n och :n för?

#n står för ett attributnamn och :n för ett värde. Båda är platshållare. #n kallas ett alias, ett ersättningsnamn för attributet. Två objekt bredvid uttrycket säger vad som ska stå där. ExpressionAttributeNames säger att #n betyder attributet name. ExpressionAttributeValues säger att :n betyder det nya namnet, som Carol. (AWS: Expression attribute names, AWS: Expression attribute values)

await db.send(new UpdateCommand({
  TableName: "v42-customers",
  Key: { id },                                  // itemet med det här id:t
  UpdateExpression: "SET #n = :n",
  ExpressionAttributeNames: { "#n": "name" },   // #n = attributet name
  ExpressionAttributeValues: { ":n": name },    // :n = det nya namnet
}));

Bokstaven n är samma, men tecknet först avgör: # gör det till ett namn, : till ett värde. (AWS: Expression attribute names, AWS: Expression attribute values)

Varför behöver name ett alias?

Ordet name är reserverat i DynamoDB. DynamoDB använder ordet själv, så det får inte stå som attributnamn i ett uttryck. Listan har flera hundra ord, till exempel status och date. Med #n står name inte i uttrycket, bara i ExpressionAttributeNames. Attributet i itemet heter fortfarande name. (AWS: Reserved words, AWS: Expression attribute names)

UpdateExpression: "SET name = :n"

ValidationException: Invalid UpdateExpression:
Attribute name is a reserved keyword

Fel Anropet stoppas och inget ändras.

UpdateExpression: "SET #n = :n"
ExpressionAttributeNames: { "#n": "name" }

Fungerar Attributet name får det nya värdet.

Sammanfattning

  • Ett uttryck är en kort text som säger vad DynamoDB ska göra. SET i UpdateItem ger ett attribut ett nytt värde.
  • #n står för ett attributnamn och förklaras i ExpressionAttributeNames. :n står för ett värde och förklaras i ExpressionAttributeValues.
  • name är ett reserverat ord, liksom status och date. I ett uttryck måste det ha ett alias, som #n.
