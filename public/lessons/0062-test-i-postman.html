Lektion 62

Test i Postman

Vad du ska veta efter lektionen Att ett test är en kort kontroll av svaret som körs efter varje anrop, och att Run kör hela collectionen i ordning.

Vad är ett test i Postman?

Ett test är en kort kontroll av svaret, skriven i JavaScript. Postman kör den varje gång svaret har kommit. (Postman: Write scripts to test API response data, kursmaterialet v41)

Testet skrivs på anropet, under fliken Scripts, delen Post-response. Resultatet syns vid svaret under fliken Test Results: grönt om kontrollen stämmer, annars rött. (Postman: Add a post-response test, kursmaterialet v41)

Ett test av statuskoden

Det här testet kontrollerar att svaret har statuskoden 200: (kursmaterialet v41, Postman: Add a post-response test)

pm.test("Status 200", () => pm.response.to.have.status(200));

Allt som börjar med pm kommer från Postman. pm.test skapar testet "Status 200", och namnet visas i Test Results. pm.response är svaret, och to.have.status(200) kontrollerar dess statuskod. Är koden en annan blir testet rött. (Postman: Validate responses)

Varje anrop får minst ett test. Blir ett test rött är det API:et som ska rättas, inte testet. (kursmaterialet v41)

Hur körs alla tester?

Run skickar alla anrop i collectionen i ordning och kör testerna efter varje svar. Klicka på collectionen och välj Run, så öppnas fönstret Collection Runner. Längst upp står antalet tester som gick igenom (passed) och inte (failed). (Postman: Collection Runner, kursmaterialet v41)

Ordningen spelar roll: anropet som skapar en kund måste gå före det som hämtar den. Du ändrar ordningen genom att dra. (Postman: Configure a collection run, kursmaterialet v41)

Kör samma anrop i samma ordning efter varje ändring i servern. Då ser du om något som fungerade har gått sönder. (kursmaterialet v41)

Sammanfattning

  • Ett test är en kort kontroll av svaret i JavaScript. Det ligger under Scripts, Post-response, och körs varje gång svaret har kommit.
  • Resultatet syns under Test Results: grönt om kontrollen stämmer, rött om inte. Rött betyder att API:et ska rättas.
  • Run öppnar Collection Runner, som skickar alla anrop i collectionen i ordning och visar passed och failed.
