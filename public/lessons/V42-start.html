Veckan i överblick: serverlösa lösningar

Vad du ska veta efter lektionen Vad veckans lösning blir och var varje begrepp passar in.

Vad bygger vi?

Ett kund-API utan egen server, serverlöst. React-appen på Amplify anropar en HTTPS-adress i API Gateway. Den anropar Lambda-funktionen v42-api, som läser och skriver DynamoDB-tabellen v42-customers.

Vad liknar det?

Express-API:et från v41. Samma routes, JSON, statuskoder, curl och Postman.

Det håller inte här: ingen server att logga in på, ingen process som väntar. Funktionen startas per anrop. Loggen ligger i CloudWatch, routen och CORS i API Gateway, inte i koden.

Veckans begrepp

  • Terminalen: CloudShell, AWS CLI (Command Line Interface), skalvariabel, kommandosubstitution, Application Load Balancer, ARN (Amazon Resource Name)
  • Funktionen: runtime, handler, event och testhändelse
  • Körningen: exekveringsmiljö, kallstart, duration, timeout
  • Rättigheter: execution role, minsta möjliga behörighet, AccessDeniedException, resource-based policy
  • Tabellen: item, partitionsnyckel, on-demand, operationer, platshållare, ConditionExpression
  • Koden: miljövariabel, AWS SDK (Software Development Kit), DocumentClient, UUID (Universally Unique Identifier)
  • Mellan Gateway och funktion: händelse, svar
  • API Gateway: integration, stage, throttling
  • Webbläsaren: preflight, miljövariabel i Vite

Efter veckan

Du kan peka ut kedjan i bilden och vilken roll som ger vilken rättighet, läsa en AccessDeniedException, och säga var CORS, routen och gränsen ligger.
