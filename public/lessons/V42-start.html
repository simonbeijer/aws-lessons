Start · V42

Veckan i överblick: serverlösa lösningar

Kort sagt Den här veckan flyttar kund-API:et (Application Programming Interface) från v41 bort från servern du själv skötte, till tjänster i AWS (Amazon Web Services) som sköter driften åt dig. API:et gör samma sak som förut, men nu kan webbsidan på Amplify anropa det.

Varför nu?

Servern från v41 måste du själv sköta, och den kör hela tiden, även när ingen använder den. Dessutom nåddes den över HTTP (Hypertext Transfer Protocol), så webbsidan på Amplify, som använder HTTPS (HTTP Secure), fick sina anrop blockerade.

Veckan byter ut servern mot tre tjänster. Lambda kör en funktion, en bit kod, först när ett anrop kommer, och du betalar per anrop. DynamoDB är databasen som AWS sköter. API Gateway ger funktionen en HTTPS-adress. Routes och statuskoder blir samma som i v41.

Hur hänger det ihop?

Veckans väg

  1. Terminalen (71–73): kommandon till AWS från en terminal i webbläsaren, och ett test av att kontot får skapa en lastbalanserare, som behövs i vecka 45.
  2. Funktionen (74–77): kod som körs utan server, och hur du ser vad den gjorde.
  3. Databasen (78–81): tabellen, rollen som får använda den, och koden mot den.
  4. Adressen utåt (82–84): API Gateway tar emot anropet och skickar det till funktionen.
  5. Webbsidan (85): sidan kopplas till API:et över HTTPS.

Efter veckan

Du kan peka ut kedjan i bilden, säga vilken del som gör vad, och läsa loggen när något går fel.
