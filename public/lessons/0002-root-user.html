Lektion 2

Root user

Vad du ska veta efter lektionen Vad root user är, och varför du bara loggar in som root när en uppgift kräver det.

Vad är root user?

Root user är inloggningen som skapas samtidigt som ditt AWS-konto. Du loggar in med e-postadressen och lösenordet du registrerade kontot med. (AWS: AWS account root user)

Root user har full åtkomst till alla tjänster och allt innehåll i kontot. (AWS: AWS account root user)

Varför används root så sällan?

För att root kan göra allt. Den som får tag i lösenordet kan också göra allt, till exempel stänga kontot. AWS rekommenderar starkt att du inte använder root till vardagliga uppgifter. (AWS: Root user best practices)

Till vardags loggar du i stället in som IAM user, en egen inloggning som du skapar i kontot. (AWS: Root user best practices)

När behövs root?

Bara för de få uppgifter som kräver root, till exempel att låta IAM users se fakturering. Klicka och se vem som gör vad. (AWS: Tasks that require root user credentials)

Bara root Tills root slår på det nekas även en IAM user med full behörighet i Billing, fakturavyn.

Bara root Samma gäller att byta root-e-posten och att stänga kontot.

IAM user Kontonamn och kontaktuppgifter kräver inte root. (AWS)

Gör så här

Logga in som root, gör uppgiften, logga ut. Allt annat gör du som IAM user.

Sammanfattning

  • Root user är inloggningen med kontots e-postadress och lösenord. Den har full åtkomst till allt i kontot.
  • Eftersom root kan göra allt är den farlig om någon annan får tag i den. Till vardags använder du en IAM user.
  • Logga bara in som root när en uppgift kräver det, till exempel för att låta IAM users se fakturering.
