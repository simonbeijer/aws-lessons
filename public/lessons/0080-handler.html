Lektion 80

Handler

Vad du ska veta efter lektionen Att handlern är den exporterade funktionen Lambda anropar (index.handler), att den får event och context, och att det den returnerar blir svaret.

Vad är en handler?

Handlern är funktionen i din kod som Lambda anropar när din Lambda-funktion körs. En funktion i JavaScript är kod med ett namn, som körs när något anropar den. (AWS: Define Lambda function handler in Node.js)

export const handler = async (event, context) => {
  return { message: "Hej!" };
};

export gör att kod utanför filen, här Lambda, kan anropa funktionen. Det är inte samma export som i bash. async låter funktionen vänta på annat, till exempel en annan AWS-tjänst. (AWS: async function handlers)

Vad betyder index.handler?

index.handler är filnamnet och funktionens namn, med en punkt emellan. Konsolen skapar filen index.mjs med en funktion som heter handler. Inställningen Handler under Runtime settings är därför index.handler. (AWS: Handler naming conventions)

Varning

Byter du namn på filen eller funktionen hittar Lambda inte handlern. Felet blir Runtime.HandlerNotFound. Ändra tillbaka, eller ändra Handler så att den stämmer.

Vad får och returnerar handlern?

Handlern får event och context, och det den returnerar blir svaret. event är indata, det anroparen skickar med. context är information om själva anropet, till exempel ett id för det. (AWS: async function handlers)

Det du skriver efter return skickas tillbaka till den som anropade. I Express skickade du svaret med res.json. Här returnerar du det. (AWS: Define Lambda function handler in Node.js)

Sammanfattning

  • Handlern är den exporterade funktionen som Lambda anropar när funktionen körs.
  • index.handler betyder funktionen handler i filen index.mjs. Stämmer inte namnen hittar Lambda inte handlern.
  • Handlern får event, indata från anroparen, och context, information om anropet. Det den returnerar blir svaret.
