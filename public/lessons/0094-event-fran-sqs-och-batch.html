Vad får handlern in från kön?

Kort sagt Triggern ger handlern meddelandena som ett event med en lista. Listan kan ha flera meddelanden, och en inställning, batch size, avgör hur många. Det styr hur mycket som körs om när något går fel.

Hur ser eventet ut?

Triggern från förra lektionen packar meddelandena i ett event, och Lambda bestämmer formen, inte producenten. Eventet har listan Records med en post per meddelande. Tre fält behövs i varje post, och alla är strängar:

{
  "Records": [
    {
      "messageId": "a1b2-…",
      "body": "{\"id\":\"c-1042\"}",
      "attributes": { "ApproximateReceiveCount": "1" }
    }
  ]
}

body är det producenten skickade, och ett meddelande är en sträng (lektion 91). ApproximateReceiveCount är receive count, antal hämtningar utan borttagning, som SQS (Simple Queue Service) själv lägger i attributes. Det är texten "1", inte talet 1. messageId är meddelandets id, bra att skriva i loggen.

Handlern går igenom listan och tolkar varje body med JSON (JavaScript Object Notation):

for (const record of event.Records) {
  const body = JSON.parse(record.body);
  const attempt = record.attributes.ApproximateReceiveCount;
}

Hur många meddelanden åt gången?

Meddelandena i ett anrop kallas en batch, och listan kan ha flera poster. Batch size är det högsta antalet. Utan inställning är det upp till 10. Med batch size 1 får handlern ett meddelande per anrop, men koden går ändå igenom en lista med en post.

Det spelar roll när något kastar. Triggern tar bara bort meddelanden efter ett lyckat anrop, så ett kast skickar tillbaka hela batchen, också de som lyckades. Med batch size 10, där nio går bra och ett kastar, kommer alla tio tillbaka och de nio körs om. Med batch size 1 drabbar ett kast bara det meddelandet. Vad som sedan händer med dem tar nästa lektion.

Quiz

1. Vad är record.body när producenten skickade JSON?

2. Batch size är 10, nio meddelanden lyckas och ett kastar. Vad händer?

3. Vad är ApproximateReceiveCount för ett meddelande som kommit tillbaka en gång?

Sammanfattning

  • Eventet har listan Records, en post per meddelande. body är en sträng som tolkas med JSON.parse, attributes.ApproximateReceiveCount en sträng med antal hämtningar och messageId meddelandets id.
  • Batch size är högsta antalet meddelanden per anrop, upp till 10 som standard. Batch size 1 ger ett meddelande per anrop.
  • Ett kast skickar tillbaka hela batchen, också de som lyckades.

Källor

Huvudkälla: AWS: Lambda med SQS, exempel på event. Dessutom AWS: konfigurera SQS-trigger för Lambda.
