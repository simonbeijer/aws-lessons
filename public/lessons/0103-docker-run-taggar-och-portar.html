Hur startar man en container?

Kort sagt Med ett kommando startar du en container från en image, och Docker hämtar imagen åt dig om den saknas. En container är stängd från omvärlden, så du måste själv öppna en port in till den. Allt annat i veckan börjar med en container som startats så här.

Vad gör docker run?

docker run -d -p 8080:80 --name web nginx:alpine

Docker letar först efter imagen på datorn. Saknas den hämtas den från ett register, en central plats som lagrar och delar images. Standardregistret är Docker Hub. Sedan skapas en container från imagen och startas.

Första gången syns hämtningen. Sedan skrivs containerns långa id ut och prompten kommer tillbaka.

Namn och flaggor

nginx:alpine är imagens namn och tagg. nginx är en webbserver, och taggen alpine väljer en variant byggd på Alpine Linux. Anger du ingen tagg används latest.

-d (detached) kör containern i bakgrunden. Utan det hänger terminalen kvar i containerns logg. --name web ger containern ett namn som senare kommandon kan använda, annars slumpar Docker ett. Finns redan en container med namnet, även en stoppad, svarar Docker att namnet "is already in use".

Hur når trafiken in?

Containern är isolerad, så ingen trafik når den av sig själv. -p 8080:80 kopplar värdens port 8080 till containerns port 80, porten som nginx lyssnar på. Värdens port står först. localhost:8080 i webbläsaren når alltså nginx.

nginx vet inget om 8080. Docker flyttar trafiken, nginx lyssnar på 80 som vanligt. Därför kan flera containrar använda port 80 inuti, med olika portar på värden.

docker ps listar körande containrar. Kolumnen PORTS visar kopplingen som 0.0.0.0:8080->80/tcp, där 0.0.0.0 betyder alla värdens adresser och tcp är protokollet TCP (Transmission Control Protocol). Är 8080 upptagen svarar Docker "port is already allocated". Välj då en annan värdport, som -p 8081:80.

Quiz

1. Du kör docker run med en image som inte finns på datorn. Vad händer?

2. Du kör docker run -d -p 9090:80 nginx:alpine. Vilken adress öppnar du i webbläsaren?

3. Två containrar kör nginx, som lyssnar på port 80 i båda. Hur kan de köra samtidigt på samma dator?

Sammanfattning

  • docker run använder imagen på datorn, hämtar den annars från registret (Docker Hub som standard), och skapar och startar en container.
  • nginx:alpine är namn och tagg. Utan tagg används latest.
  • -d kör i bakgrunden. --name web ger containern ett namn.
  • -p 8080:80 kopplar värdens port till containerns, värden först. Programmet i containern vet inget om 8080.
  • PORTS i docker ps visar 0.0.0.0:8080->80/tcp. "port is already allocated" betyder att värdporten är upptagen, "name is already in use" att namnet är det.

Källor
