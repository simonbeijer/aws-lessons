Lektion 81

Event och testhändelse

Vad du ska veta efter lektionen Att event är det som anroparen skickar med, och att en testhändelse är ett event du själv skriver i JSON i konsolen.

Hur ser ett event ut?

Ett event är JSON som anroparen skickar med när den kör funktionen, till exempel: (AWS: Event-driven architectures)

{ "name": "Alice" }

Lambda gör om JSON:en så att koden kan läsa den, och ger den till handlern som event. Koden läser värdet med event.name och får "Alice". Efter punkten står namnet i JSON-objektet. (AWS: Testing functions in the console)

Vad eventet innehåller bestämmer anroparen. En AWS-tjänst som anropar funktionen skickar JSON i sitt eget format. (AWS: Event-driven architectures)

Vad är en testhändelse?

En testhändelse är ett event du själv skriver i JSON i konsolen. Då är du anroparen. (AWS: Testing functions in the console)

Klicka Test i editorn. Skriv ett namn under Event name och JSON:en i rutan Event JSON. Klicka Save och sedan Test. Lambda kör funktionen med din JSON som event och visar svaret. (AWS: Invoking with test events)

Behöver funktionen ingen indata räcker ett tomt JSON-objekt: {} (AWS: Testing functions in the console)

Varför spara testhändelser?

En sparad testhändelse kan du köra igen med ett klick. Du kan spara upp till 10 privata testhändelser per funktion, till exempel en för varje fall du vill pröva. Privata ser bara du. (AWS: Creating private test events)

Klickar du Test utan att spara finns händelsen bara kvar tills du lämnar konsolen. (AWS: Invoking with test events)

Quiz

1. Du skriver en testhändelse i konsolen. Vad är den?

2. Testhändelsen är { "name": "Alice" }. Vad får koden av event.name?

3. Repetition från lektion 52: du skriver testhändelsen { 'name': 'Alice' }. Vad är fel?

Sammanfattning

  • Ett event är JSON som anroparen skickar med. Handlern får det som event, och event.name ger värdet för name.
  • En testhändelse är ett event du själv skriver i JSON i konsolen. Då är du anroparen.
  • Spara testhändelser, upp till 10 privata per funktion, så kan du köra dem igen med ett klick.
