Lektion 132

Batch size

Vad du ska veta efter lektionen Att batch size är det högsta antalet meddelanden i ett anrop, att batch size 1 ger ett meddelande per anrop, och att ett kast skickar tillbaka alla meddelanden i batchen.

Vad är batch size?

Batch size är det högsta antalet meddelanden som triggern skickar till funktionen i ett anrop. Meddelandena i ett anrop kallas en batch, och de ligger som poster i Records. Utan inställning är det upp till 10. Med batch size 1 får funktionen ett meddelande per anrop. (AWS: Lambda med SQS)

Större batch tar längre tid per anrop. Funktionens timeout måste räcka för hela batchen, så vid långsamma jobb väljs en mindre batch. För en standardkö kan batch size vara upp till 10 000, för en FIFO-kö högst 10. (AWS: konfigurera SQS-trigger)

Vad händer vid ett kast?

Kastar funktionen ett fel (ett kast) kommer alla meddelanden i batchen tillbaka till kön, inte bara det som misslyckades. Lyckas funktionen tar triggern bort alla meddelanden i batchen. (AWS: konfigurera SQS-trigger)

Exempel med batch size 10: nio meddelanden går bra och ett kastar. Alla tio kommer tillbaka, även de nio som redan lyckats. Med batch size 1 påverkar ett kast bara ett meddelande.

  • Batch size är det högsta antalet meddelanden i ett anrop. Utan inställning är det upp till 10.
  • Batch size 1 ger ett meddelande per anrop.
  • Ett kast skickar tillbaka alla meddelanden i batchen, även de som lyckades.
