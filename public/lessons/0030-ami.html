AMI

Vad du ska veta efter lektionen Att en AMI är avbilden servern startar från, t.ex. Amazon Linux 2023.

Vad är en AMI?

En AMI (Amazon Machine Image) är avbilden servern startar från. Den innehåller programvaran som behövs för att starta servern, främst operativsystemet: grundprogrammet som styr datorn, t.ex. Linux eller Windows. (AWS: Amazon Machine Images)

Du måste välja en AMI när du startar en instans. Från samma AMI kan du starta flera servrar som blir likadana. (AWS: Amazon Machine Images)

Var väljer du AMI?

Du väljer AMI under Application and OS Images i guiden Launch instances. Fliken Quick Start visar vanliga AMI:er, sorterade efter operativsystem. (AWS: Application and OS Images)

AMI:er kommer från AWS, från andra användare eller från AWS Marketplace, en butik där vissa AMI:er kostar pengar. Märkningen Verified provider betyder att AMI:n kommer från Amazon eller en granskad partner. (AWS: Application and OS Images, AWS: Paid AMIs)

Varför Amazon Linux 2023?

Amazon Linux 2023 passar kursen eftersom den är AWS egen Linux och inte kostar något extra utöver servern. (AWS: What is Amazon Linux 2023?)

Den har också EC2 Instance Connect färdigt installerat. Det är tjänsten som låter dig skriva kommandon till servern direkt i webbläsaren. Med en annan AMI kan den saknas. (AWS: Install EC2 Instance Connect)

Kursen väljer arkitekturen 64-bit (x86). Arkitekturen är den sorts processor AMI:n är byggd för, och den måste passa instanstypen. (AWS: Amazon Machine Images)
