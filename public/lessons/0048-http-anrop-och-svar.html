Lektion 48

HTTP-anrop och svar

Vad du ska veta efter lektionen Att ett HTTP-anrop och svaret på det har samma form: en startrad, headers, en tom rad och sedan kroppen.

Vad är ett anrop och ett svar?

Ett HTTP-anrop är ett meddelande som en klient skickar till en server för att be om något. Svaret är meddelandet servern skickar tillbaka. (MDN: HTTP messages)

Klienten är programmet som skickar anropet, t.ex. webbläsaren. HTTP är sättet den hämtar sidor på. (MDN: HTTP messages)

Vilka delar har ett anrop och ett svar?

Anrop och svar har fyra delar: startrad, headers, tom rad och kropp. Kursens exempel skapar en kund: (kursens lektion sida 14, RFC 9112: Message format)

Anropet, från klienten

POST /customers HTTP/1.1
Host: 16.170.12.34:3000
Content-Type: application/json

{ "name": "Carol" }

Svaret, från servern

HTTP/1.1 201 Created
Content-Type: application/json

{ "id": 3, "name": "Carol" }
DelVad den gör
StartradFörsta raden. I anropet: vad klienten vill och var. I svaret: hur det gick. Båda har versionen, HTTP/1.1.
HeadersEn rad per uppgift om meddelandet. Host säger vart anropet ska: serverns IP-adress och port.
Tom radSäger att headers är slut.
KroppInnehållet: det klienten skickar eller servern lämnar tillbaka.

POST, 201 och headers får egna lektioner. (MDN: Anatomy of an HTTP message)

Hur skiljer sig ett anrop från ett svar?

Anrop och svar är byggda likadant. Bara startraden skiljer: anropet säger vad klienten vill, svaret hur det gick. (kursens lektion sida 14)

Läs därför ett svar uppifrån: startrad, headers och kroppen efter den tomma raden. Ett anrop som bara hämtar något har ingen kropp. (MDN: Request body)

Står det HTTP/2 i startraden är det en nyare version. Delarna betyder samma sak. (MDN: HTTP/2 messages, kursmaterialet v41)

Sammanfattning

  • Ett HTTP-anrop är ett meddelande från en klient, t.ex. webbläsaren, till en server. Svaret är meddelandet servern skickar tillbaka.
  • Båda har fyra delar i samma ordning: startrad, headers, en tom rad och kroppen.
  • Bara startraden skiljer: anropet säger vad klienten vill, svaret hur det gick. Kroppen kan saknas.

Källor

Huvudkälla: MDN: HTTP messages.

Standarden för formen: RFC 9112: HTTP/1.1, Message format.
