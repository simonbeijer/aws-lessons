Lektion 64

YAML

Vad du ska veta efter lektionen Att YAML är ett textformat där indraget bär betydelse, och att ett fel indrag stoppar servern.

Vad är YAML?

YAML är ett textformat för data, som JSON, men gjort för att vara lätt att läsa. Varje rad är nyckel, kolon, mellanslag och värde, utan klamrar. (YAML 1.2.2, YAML: Block mappings)

Samma kund som i lektion 52:

JSON

{ "id": 3, "name": "Carol" }

YAML

id: 3
name: Carol

Filen openapi.yaml är skriven i YAML. Den beskriver API:et, mer om det i nästa lektion, och servern läser den när den startar. (kursmaterialet v41)

Varför spelar indraget roll?

Indraget, mellanslagen först på raden, visar vad som hör ihop. En rad längre in hör till raden ovanför. Rader som hör till samma sak står exakt lika långt in. Tabbar (tabbtangentens tecken) får inte användas. (kursmaterialet v41, YAML: Indentation spaces) Klicka och jämför:

customer:
  id: 3
  name: Carol

Giltig Båda hör till customer.

customer:
  id: 3
name: Carol

Annan betydelse name hör inte längre till customer.

customer:
  id: 3
 name: Carol

Fel name står varken lika långt in som id eller längst till vänster. (yaml: Errors)

Fel i indraget

Ett ojämnt indrag gör filen ogiltig, och då startar servern inte. Felet syns i server.log som YAMLParseError med rad och kolumn (hur många tecken in felet sitter). (kursmaterialet v41, yaml: Errors)

Nästan alltid är det ett indrag eller en tabb. Jämför raden med raden ovanför. (kursmaterialet v41)

”Ett steg för lite” är giltig YAML. Då startar servern, men en del av API-beskrivningen saknas. (kursmaterialet v41)

Quiz

1. Vad visar i YAML vilka rader som hör ihop?

2. id står två mellanslag in och name på raden under står ett mellanslag in. Vad händer när servern startar?

3. Repetition från lektion 60: servern startas med nohup node server.js > server.log 2>&1 & men startar inte. Var syns felmeddelandet?

Sammanfattning

  • YAML är ett textformat för data, som JSON, men utan klamrar. Varje rad är nyckel: värde.
  • Indraget visar vad som hör ihop. Rader som hör till samma sak står exakt lika långt in, med mellanslag, aldrig tabb.
  • Servern läser YAML-filen när den startar. Ett fel indrag ger YAMLParseError i server.log med rad och kolumn, och servern startar inte.

Källor

Huvudkälla: YAML 1.2.2: Indentation spaces (indrag och tabbar).

Om felmeddelandet: yaml (paketet för Node): Errors.
