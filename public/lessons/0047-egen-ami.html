Lektion 47

Egen AMI

Vad du ska veta efter lektionen Att en egen AMI kopierar serverns disk men inte kör user data igen, och skillnaden mellan att baka in något och att göra det vid start.

Vad är en egen AMI?

En egen AMI är en AMI du gör av din server. Den kopierar serverns disk, med allt du installerat, och nya servrar startar från kopian. (AWS: Create an Amazon EBS-backed AMI)

Du skapar den under EC2 → Instances: markera servern, Actions → Image and templates → Create image. AWS tar då en snapshot av disken. (AWS: Create an AMI from an instance, kursmaterialet v40)

Varning

Deregister AMI tar bort AMI:n. Dess snapshot blir kvar och kostar lagring tills du raderar den. Med Free plan räknas det av mot krediterna. (AWS: Overview of AMI creation, AWS: Deregister an AMI, kursmaterialet v40, AWS: Choosing a plan)

Varför user data inte körs igen

User data hör till servern, inte disken. Den följer därför inte med i AMI:n. (AWS: Run commands with user data)

Det skriptet gjorde ligger kvar på disken. Kursens exempel: skriptet skrev en webbsida som visar zonen, eu-north-1a. En ny server från AMI:n i eu-north-1b visar ändå eu-north-1a. (kursmaterialet v40)

Vad betyder baka in och göra vid start?

Att baka in betyder att något ligger färdigt i AMI:n. Att göra vid start betyder att ett skript gör det när servern startar. (kursmaterialet v40)

Baka in

Det som ska vara lika på alla servrar, t.ex. program. Servern startar snabbare.

Gör vid start

Det som skiljer servrarna åt, t.ex. zonen.

(AWS: User data and shell scripts, kursmaterialet v40)

En server är AMI plus user data. En egen AMI bakar in det user data gjorde. (kursens lektion sida 37)

Sammanfattning

  • En egen AMI är en kopia av din servers disk. Nya servrar kan starta från den. Du skapar den med Actions → Image and templates → Create image.
  • User data följer inte med in i AMI:n och körs inte igen. Det skriptet skrev på disken finns däremot kvar.
  • Baka in det som ska vara lika på alla servrar. Gör det som skiljer dem åt vid start.
  • Deregister AMI tar bort AMI:n. Snapshoten kostar lagring tills du raderar den. Med Free plan räknas det av mot krediterna.
