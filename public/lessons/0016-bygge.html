Lektion 16

Bygge (build)

Vad du ska veta efter lektionen Att React-kod byggs till HTML, CSS och JavaScript i mappen dist/ innan en webbläsare kan visa den.

Vad är ett bygge?

Ett bygge gör om koden du skriver, källkoden, till färdiga filer som en webbläsare kan visa: HTML, CSS och JavaScript. (Vite: Building for production)

React är ett JavaScript-bibliotek för att bygga webbsidor. React-kod skrivs i JSX, HTML-liknande kod inne i JavaScript, i filer som App.jsx. JSX görs om till vanlig JavaScript. Det sköter bygget. (React: Writing markup with JSX)

Var hamnar filerna?

I mappen dist/. Det gäller projekt som använder Vite, ett byggverktyg för bland annat React. Bygget startar med kommandot nedan, i projektmappen. npm är verktyget som kör projektets kommandon, här build. (Vite: Deploying a static site)

npm run build

src/

Källkoden du skriver och ändrar, till exempel App.jsx.

dist/

Det färdiga resultatet. Bygget skapar filerna, du ändrar inget här.

Vad som publiceras

Bara innehållet i dist/ publiceras. Som i Static website hosting skickas filerna precis som de ligger, så de måste redan vara färdiga. (Vite: Deploying a static site)

En AWS-tjänst som bygger åt dig behöver veta var de färdiga filerna ligger. I AWS Amplify heter inställningen baseDirectory: mappen där de färdiga filerna finns. För Vite är det dist. (AWS: Build specification reference)

Quiz

Sammanfattning

  • Ett bygge gör om källkoden, till exempel React-kod i JSX, till HTML, CSS och JavaScript som en webbläsare kan visa.
  • I ett Vite-projekt startar npm run build bygget, och de färdiga filerna hamnar i dist/.
  • Det är dist/ som publiceras, inte källkoden. I AWS Amplify pekar baseDirectory: dist ut mappen.
