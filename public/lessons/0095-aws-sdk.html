Lektion 95

AWS SDK

Vad du ska veta efter lektionen Att AWS SDK är biblioteket din kod använder för att anropa AWS-tjänster, att det redan finns i Lambda, och varför klienten skapas utanför handlern.

Vad är AWS SDK?

AWS SDK är ett bibliotek med färdig kod för att anropa AWS-tjänster. SDK står för software development kit. För Node.js heter det AWS SDK for JavaScript v3. (AWS: What's the AWS SDK for JavaScript?)

SDK:n har ett paket per tjänst. @aws-sdk/client-dynamodb anropar till exempel DynamoDB, databastjänsten från lektion 88. (AWS: Get started with Node.js)

Alla Node.js-runtimes som Lambda stöder har SDK:n med. Därför behövs ingen npm install i konsolens editor. (AWS: Using the SDK for JavaScript v3 in your handler)

Hur anropar koden AWS?

Koden använder en klient och ett kommando. Klienten skickar anropen till tjänsten, som klienten i ett HTTP-anrop. Kommandot säger vad tjänsten ska göra. (AWS: Using the SDK for JavaScript v3 in your handler)

import { DynamoDBClient, ListTablesCommand } from "@aws-sdk/client-dynamodb";

const client = new DynamoDBClient({}); // en gång per miljö

export const handler = async (event) => {
  const svar = await client.send(new ListTablesCommand({})); // varje anrop
  return svar.TableNames;
};

import hämtar klienten och kommandot ur paketet. new DynamoDBClient({}) skapar klienten, och {} betyder standardinställningar. client.send skickar kommandot, här att lista tabellerna, och await väntar på svaret. (AWS: DynamoDB examples, ListTables, AWS: ListTables)

Varför utanför handlern?

Utanför handlern skapas klienten en gång per miljö, inte vid varje anrop. Koden utanför handlern körs bara när en ny exekveringsmiljö startar, vid en kallstart. Sedan återanvänds den i varje anrop. (AWS: Using global state)

Inuti handlern skapas klienten om vid varje anrop. Anropen tar längre tid, och Lambda tar betalt för tiden funktionen kör. (AWS: Best practices, function code)

Tre anrop: klienten skapas en gång, vid kallstarten, och återanvänds.

Tre anrop: klienten skapas tre gånger, en gång i varje anrop.

Sammanfattning

  • AWS SDK är biblioteket din kod använder för att anropa AWS-tjänster. Det är uppdelat i ett paket per tjänst, till exempel @aws-sdk/client-dynamodb.
  • SDK:n finns redan i Lambdas Node.js-runtimes. Ingen npm install behövs i konsolens editor.
  • Koden skapar en klient och skickar kommandon med client.send. Klienten skapas utanför handlern: en gång per miljö, och återanvänds i varje anrop.
