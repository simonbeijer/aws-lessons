Lektion 90

Partitionsnyckel

Vad du ska veta efter lektionen Att partitionsnyckeln, här id, är det enda du bestämmer i förväg om itemen i en DynamoDB-tabell, och att varje item måste ha den med ett eget värde.

Vad är en partitionsnyckel?

Partitionsnyckeln är det attribut som varje item i en DynamoDB-tabell måste ha, till exempel id. Ett item är en rad i tabellen, och dess attribut är par av namn och värde, som i lektion 89. (AWS: Tables, items, and attributes)

{ "id": "demo-1", "name": "Alice" }

Namnet kommer av att DynamoDB använder värdet för att välja var itemet lagras, i en partition. (AWS: Primary key)

Vad bestäms i förväg?

Om itemen bestäms bara partitionsnyckeln. När du skapar tabellen anger du nyckelns namn och typ, till exempel id med typen String. (AWS: Primary key)

Alla andra attribut väljer varje item själv, så två items kan ha olika attribut, som i lektion 89. (AWS: Tables, items, and attributes)

Vilka items går att spara?

Bara items som har partitionsnyckeln går att spara. Värdet skiljer itemet från alla andra, och med det hämtar du itemet direkt. Sparar du ett item med ett id som redan finns, ersätter det nya det gamla helt. (AWS: PutItem)

{ "id": "demo-1", "name": "Alice" }

Sparas Itemet har id.

{ "id": "demo-2", "name": "Carol", "created_at": "2026-10-22" }

Sparas Ett attribut till är tillåtet. Bara id är obligatoriskt.

{ "name": "Alice" }

Nekas Partitionsnyckeln saknas, så DynamoDB sparar inte itemet.

Sammanfattning

  • Partitionsnyckeln är det attribut som varje item måste ha. DynamoDB använder värdet för att välja partition.
  • Partitionsnyckeln, här id med typen String, är det enda du bestämmer i förväg. Övriga attribut väljer varje item själv.
  • Ett item utan partitionsnyckeln sparas inte. Värdet pekar ut ett enda item, och ett nytt item med samma värde ersätter det gamla.
