Lektion 58

localhost

Vad du ska veta efter lektionen Att localhost betyder datorn som kör kommandot, och varför du testar API:et på servern innan du testar från din dator.

Vad är localhost?

localhost är namnet på datorn som kör kommandot. Namnet ger alltid en loopback-adress, till exempel 127.0.0.1, en adress som pekar tillbaka på samma dator och aldrig syns utanför den. Anropet lämnar alltså aldrig datorn. (RFC 6761: localhost, RFC 1122: loopback)

Med en port efter kolonet betyder http://localhost:3000 programmet på port 3000 på samma dator.

Samma ord, olika datorer

Vilken dator localhost är beror på var du skriver det. (kursmaterialet v41)

På servern

I terminalen i EC2 Instance Connect är localhost servern. Där når anropet ditt Express-program.

På din Mac

I Terminal på din Mac är localhost din Mac. Där kör inget API. Använd serverns publika IP i stället.

Så testar du API:et på servern:

curl -i http://localhost:3000/customers

Varför testa på servern först?

Där testar du bara programmet. Ett anrop till localhost på servern lämnar aldrig servern och passerar därför ingen security group. Svarar det, fungerar programmet. (AWS: Security groups, RFC 1122: loopback)

Kursens poäng: får du timeout från din dator, testa curl http://localhost:3000 på servern först. Svarar det där, ligger felet i vägen dit, inte i koden. Oftast saknas regeln för port 3000, eller så har My IP en gammal adress. (kursmaterialet v41, kursens lektion sida 17, AWS: Connection timed out)

Quiz

1. API:et kör på servern. Du kör curl -i http://localhost:3000/customers i Terminal på din Mac. Vart går anropet?

2. På servern svarar curl http://localhost:3000/customers med 200. Från din Mac blir det timeout. Var ligger felet?

3. Repetition från lektion 35: regeln för port 3000 har källan My IP. Du byter till ett annat wifi. Vad händer?

Sammanfattning

  • localhost är datorn som kör kommandot. Det ger en loopback-adress, t.ex. 127.0.0.1, och anropet lämnar aldrig datorn.
  • På servern är localhost servern. På din Mac är det din Mac. Från din Mac når du servern via dess publika IP.
  • Testa curl http://localhost:3000 på servern först. Svarar det där men inte från din dator, ligger felet i nätverket, t.ex. security group-regeln, inte i koden.

Källor

Huvudkälla: RFC 6761: localhost.

Om timeout från din dator: AWS EC2: Connection timed out.
